# 一句話改狀態並回報作業結果

> 沿用 `ch10/ex1.md` 的虛構追蹤表（青禾手作食品，A01～A09）。模擬的今天是 2026-11-16（一）。

## 一、技能設計：meeting-secretary

```markdown
---
name: meeting-secretary
description: 管理經營會議的行動項目追蹤表：新增會議交辦事項、更新項目狀態、查詢還有幾件沒完成，並產出晨報。使用時機：(1) 使用者要把會議紀錄裡的待辦加進追蹤表，(2) 使用者要改某個編號的狀態或負責人，(3) 使用者問還有哪些事沒做完。常見說法：「把 A03 改成已完成」「A05 做完了」「還有幾件沒完成」「幫我把會議待辦加進去」「誰的事還沒交」「更新一下追蹤表」。關鍵詞：行動項目、追蹤表、待辦、交辦、狀態、完成、晨報、會議紀錄。
---

# 會議秘書

## 使用說明

1. **資料位置**：只讀寫試算表「行動項目追蹤表」的「行動項目」分頁；欄位固定為「編號、行動項目、負責人、期限、狀態」，不新增欄位、不改欄位順序。
2. **找不到就停**：使用者指定的編號在表中找不到時，不新增、不修改任何列，也不猜測是哪一筆；直接回報找不到，並列出現有的編號範圍。
3. **只改被指定的欄位**：改狀態就只改「狀態」欄，其他欄位與其他列一律不動；狀態只接受「未開始、進行中、已完成」三種。
4. **沒講的不編**：新增項目時，會議紀錄沒提到的負責人或期限一律填「待確認」。
5. **固定作業回報**：每次動作後，不論成功或失敗，都固定回報四件事：
   - 寫入列數（這次新增或修改了幾列）
   - 異動分頁（改到哪個分頁；沒改就寫「無」）
   - 待辦筆數（狀態不是「已完成」的項目數）
   - 郵件狀態：**本技能不寄信**，固定寫「未寄信」
```

## 三、模擬：「把 A99 改成已完成」（編號不存在）

**執行過程：**

1. 在「行動項目」分頁找編號 A99 → **找不到**。
2. 依規則 2 停止，不修改任何列，也不猜是哪一筆。

**Spark 的回覆：**

> ⚠️ **沒有修改任何資料。**追蹤表裡找不到編號 A99，目前的編號是 A01～A09。
> 請確認是不是要改其他編號（例如 A09「評估是否新增一台冷藏設備」）？告訴我正確編號後我再修改。
>
> **作業回報**
>
> - 寫入列數：0 列
> - 異動分頁：無
> - 待辦筆數：7 筆（沒有變動）
> - 郵件狀態：未寄信（本技能不寄信）

**不應該出現的回應（反面教材）：**

- ❌「好的，A99 已改成已完成！」→ 假裝成功，你會以為事情做完了。
- ❌ 自己判斷「應該是 A09」就直接改 → 改錯一筆，而且你不知道。
- ❌ 新增一列 A99 再標成已完成 → 表裡多出一筆不存在的項目。

## 四、為什麼要固定要求作業回報？

代理人說「好了」不代表真的做對了。固定回報寫入列數、異動分頁、待辦筆數和郵件狀態，等於每次都附上一張可以核對的收據：改一筆應該是 1 列，失敗應該是 0 列，待辦筆數也能跟上一次對照，數字對不上就能立刻發現問題。最重要的是，像 A99 這種找不到的情況，回報會明確寫出「0 列、無異動」，代理人就沒辦法用一句「完成了」帶過；郵件狀態每次都寫，也能確認它沒有在你不知道的時候寄出任何信。
