# 第 18 章 練習 1：用七欄位生成一份任務指令

（以「指令生成器」身分回答；一句話想法「幫我整理這週的會議紀錄」，情境為虛構）

## 1. 七欄位表：`ch18/command-form.md`

- **目標**：把這週 3 場會議整理成週摘要（決議、待辦、待討論）。
- **資料來源**：可讀「會議紀錄/2026-W47」中 11-16～11-20 的 3 份紀錄；不讀其他週、信箱、聊天訊息、人事財務資料夾，不上網。
- **執行步驟（6 步）**：先回報找到的檔案 → 逐份抓三類內容 → 待辦整理成事項／負責人／期限／出處 → 合併重複 → 依期限排序 → 寫成週摘要並回報。
- **判斷規則**：負責人沒寫或只寫「行銷部」「大家」→ 標**待確認**，不推測；期限沒寫也標待確認；內容矛盾兩種都列；不加評論。
- **輸出**：`會議紀錄/2026-W47/週摘要_2026-W47.md`，分四段，第一行寫產生時間。
- **時間**：現在執行一次，不設排程。
- **權限邊界（4 條）**：不改刪移原始紀錄；不寄信不分享；不建日曆活動、不指派任務；只新建這一個檔案。
