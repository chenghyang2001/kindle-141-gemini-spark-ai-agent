# 七欄位指令表：「幫我整理這週的會議紀錄」

> 情境為虛構範例：某行銷部專員，這週（2026-11-16～11-20）開了 3 場會，紀錄都放在雲端硬碟。

| 欄位 | 內容 |
| --- | --- |
| **目標** | 把這週 3 場會議的紀錄整理成一份週摘要，讓我週五下班前一眼看完：每場會決議了什麼、誰要做什麼、哪些事還沒結論。 |
| **資料來源** | **可讀**：雲端硬碟「會議紀錄/2026-W47」資料夾裡，檔名日期在 11-16～11-20 的會議紀錄文件（共 3 份：週一部門週會、週三活動籌備會、週四廠商會議）。**不要讀**：其他週的資料夾、信箱、聊天訊息、人事或財務資料夾；也不要上網補資料。 |
| **執行步驟** | (1) 列出資料夾中符合日期的檔案，先回報找到幾份、檔名是什麼。(2) 逐份讀取，抓出「決議」「待辦」「待討論」三類內容。(3) 待辦整理成「事項／負責人／期限／出自哪場會」。(4) 把 3 場會的同一件事合併，例如兩場會都提到同一個廠商報價，只列一次並註明出處。(5) 依期限由近到遠排序待辦。(6) 寫成週摘要檔，最後附作業回報。 |
| **判斷規則** | 紀錄裡**沒寫負責人，或只寫「行銷部」「大家」這種不是具體一個人的**，負責人一律標「待確認」，不從職稱或過去經驗推測；期限沒寫也標「待確認」。紀錄中前後矛盾的內容（例如兩場會講的日期不同），兩種說法都列出並標「矛盾，待確認」。只整理紀錄裡寫的內容，不加評論或建議。 |
| **輸出位置與格式** | 存到「會議紀錄/2026-W47/」資料夾，檔名 `週摘要_2026-W47.md`。內容分四段：一、本週會議清單（日期、會議名稱）；二、決議；三、待辦事項（表格：事項／負責人／期限／出處）；四、待討論。檔案第一行寫產生時間。 |
| **時間或觸發** | 現在執行一次；不設排程。 |
| **權限邊界** | (1) 不修改、不刪除、不移動任何原始會議紀錄。(2) 不寄信、不發訊息，也不把摘要分享給任何人。(3) 不在日曆建立活動，也不替任何人指派任務。(4) 除了新建這一份週摘要檔，不建立或修改其他檔案。 |
