# 提示詞範本庫：把粗糙指令改寫成七欄位

> 4 句粗糙指令皆為虛構範例。改寫後的指令中，**【括號】是佔位符**，使用前請換成自己的資料，不要原樣貼上。

## 一、七個欄位

| 欄位 | 要回答的問題 |
| --- | --- |
| **目標** | 做完之後，我想得到什麼結果？ |
| **資料來源** | 它可以讀什麼？哪些不准讀？ |
| **執行步驟** | 依什麼順序做？第一步先回報什麼？ |
| **判斷規則** | 遇到不確定、缺資料、例外時怎麼辦？ |
| **輸出位置與格式** | 結果放哪裡、長什麼樣子、檔名怎麼取？ |
| **時間或觸發** | 現在做一次，還是什麼時候自動做？ |
| **權限邊界** | 能做什麼？絕對不能做什麼？ |

---

## 二、範本

### 範本 1：「幫我整理一下收件匣」

**壞在哪：**沒說「整理」是要分類、刪除還是封存，也沒限定範圍，代理人可能把重要的信封存或刪掉。

| 欄位 | 改寫內容 |
| --- | --- |
| 目標 | 把收件匣中最近【7】天的未讀信件分類，讓我知道哪些需要回覆。 |
| 資料來源 | 只讀收件匣中【近 7 天】的未讀信；不讀已封存、垃圾郵件與【私人標籤名稱】底下的信。 |
| 執行步驟 | (1) 先回報找到幾封 (2) 依「需要回覆／僅供參考／電子報／可疑」四類分類 (3) 每封寫一句摘要 (4) 列出建議加上的標籤。 |
| 判斷規則 | 判斷不出類別就歸「待我確認」；看起來像釣魚信的只標註風險，不點任何連結。 |
| 輸出位置與格式 | 在對話中回覆一張表格：寄件人、主旨、類別、一句摘要、建議標籤。 |
| 時間或觸發 | 現在執行一次。 |
| 權限邊界 | **能做**：讀信、分類、寫摘要、建議標籤。**不能做**：不刪除、不封存、不標示已讀、不寄信或回覆、不點開信中連結；加標籤也要等我確認後才做。 |

### 範本 2：「把資料寫進表格」

**壞在哪：**沒說是什麼資料、寫進哪份表、哪些欄位，代理人可能新增欄位、覆蓋舊資料，或自己補上缺的值。

| 欄位 | 改寫內容 |
| --- | --- |
| 目標 | 把【資料名稱】登記進【試算表名稱】的【分頁名稱】，每筆一列。 |
| 資料來源 | 只用我在對話中貼上的【資料內容】；不讀其他檔案，不上網查資料。 |
| 執行步驟 | (1) 先列出準備寫入的筆數與預覽 (2) 依欄位【欄位 1、欄位 2、欄位 3】對應 (3) 接在最後一列之後新增 (4) 回報寫入結果。 |
| 判斷規則 | 缺少的欄位填「待確認」，不自己推測；日期一律寫成【日期格式】純文字；和既有資料重複的列先列出來問我。 |
| 輸出位置與格式 | 寫入【試算表名稱】／【分頁名稱】；完成後回報「寫入 N 列、總列數 M 列」。 |
| 時間或觸發 | 現在執行一次。 |
| 權限邊界 | **能做**：在最後面新增列。**不能做**：不修改或刪除既有列、不新增或改名欄位、不排序、不建立新的工作表、不分享這份試算表。 |

### 範本 3：「回覆這封信」

**壞在哪：**沒說要回什麼立場、什麼語氣，也沒說能不能直接寄出，代理人可能答應對方沒確認的條件並直接送出。

| 欄位 | 改寫內容 |
| --- | --- |
| 目標 | 針對【寄件人】寄來、主旨為【信件主旨】的信，擬一封回覆草稿。 |
| 資料來源 | 只讀這一封信與同一串的往來信件；不讀其他信，也不查我的日曆或檔案。 |
| 執行步驟 | (1) 用一句話摘要對方要什麼 (2) 依我的立場【我的回覆重點】擬草稿 (3) 列出信中我還沒決定、需要我補充的地方。 |
| 判斷規則 | 先講結論；涉及金額、日期、承諾的內容，我沒提供就寫【待確認】，不自己答應；語氣【正式／親切】，【150】字以內。 |
| 輸出位置與格式 | 存成這封信的回覆草稿，草稿開頭標明「草稿，未寄出」。 |
| 時間或觸發 | 現在執行一次。 |
| 權限邊界 | **能做**：讀這封信、擬草稿、存草稿。**不能做**：不寄出、不轉寄、不加入其他收件人或副本、不附加任何檔案、不代替我答應任何條件。 |

### 範本 4：「每天提醒我」

**壞在哪：**沒說提醒什麼、幾點、用什麼方式、提醒到什麼時候為止，代理人可能每天寄信給別人，或一直跑下去沒人關。

| 欄位 | 改寫內容 |
| --- | --- |
| 目標 | 每天提醒我【要提醒的事】，並列出今天相關的待辦。 |
| 資料來源 | 只讀【待辦清單或行事曆名稱】中今天到期的項目；不讀信件或其他檔案。 |
| 執行步驟 | (1) 讀取今天到期的項目 (2) 依時間排序 (3) 產出一段 5 行以內的提醒。 |
| 判斷規則 | 今天沒有任何項目時，就寫「今天沒有到期的項目」，不要產生空白提醒；讀取失敗時寫「讀取失敗」並附原因。 |
| 輸出位置與格式 | 存到【資料夾名稱】，檔名【提醒_YYYY-MM-DD】，第一行寫產生時間；每天一個新檔，不覆蓋舊檔。 |
| 時間或觸發 | 每天【07:00】執行，排程名稱加上【練習_】前綴；執行到【結束日期】後自動停止，或由我手動暫停。 |
| 權限邊界 | **能做**：讀取指定清單、在指定資料夾新增提醒檔。**不能做**：不寄信、不傳訊息給任何人、不修改或刪除待辦項目、不建立其他排程、不在指定資料夾以外寫檔。 |

## 三、使用前檢查表

使用任何一則範本之前，逐條確認：

- [ ] 所有【括號佔位符】都已換成我自己的內容，文件裡已經**找不到任何【】**。
- [ ] 「資料來源」的範圍我自己縮小過，寫的是我真正要它讀的那一份，而不是整個信箱或整個雲端硬碟。
- [ ] 「判斷規則」至少有一條是**我自己的情境才有的例外**（例如某位客戶要特別處理），不是只沿用範本原句。
- [ ] 「權限邊界」的「不能做」我逐條讀過，確認跟我實際開啟的權限一致；有對外送出的動作都設定成先存草稿或先問我。
- [ ] 我先用**虛構或測試資料**跑過一次，看過結果、對照過原始資料，才拿去處理真實資料。
