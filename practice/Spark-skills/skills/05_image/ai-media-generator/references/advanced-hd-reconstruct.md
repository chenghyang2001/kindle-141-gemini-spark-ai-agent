# 進階用法：線稿重建法（HD Reconstruction）

## 適用場景

當使用 GPT-4o 反覆編輯同一張圖時，每次修改會繼承並放大前一版的瑕疵（噪點、壓縮痕跡、高頻雜訊），導致：
- 畫面越來越髒、越來越糊
- 出現油膩感、細節破碎
- 光影越來越不自然

此流程透過「拆分風格與結構」來重建乾淨的高清版本。

> ⚠️ 產品圖效果有限（對精度要求極高），主要適用於人物與場景類圖片。

---

## 流程

### Step 1：原圖 → 極簡黑白線稿

將以下 Prompt 餵給 GPT-4o 或 `imagegen`，上傳原圖：

```
將參考圖轉換為極簡高級的黑白建築線稿風格。僅使用純黑線條與純白背景，不使用任何灰階、顏色或材質渲染。保留原始場景的空間結構、人物／物件輪廓、褶皺、家具線條、物品邊緣與建築邊界，不得新增、刪除或改動任何元素。

以乾淨、清晰、精準的線條表現畫面，使用可控的線條粗細區分前景、中景與遠景：前景線條較粗，中景適中，遠景較細。只保留核心結構與必要細節，紋理需以簡化線條表現，不做寫實材質或陰影處理。

禁止上色，禁止灰階，禁止大面積明暗鋪色，禁止濃重陰影，禁止密集排線，禁止交叉排線，禁止網點，禁止漫畫風、動漫風、二次元誇張風格，禁止水彩、鉛筆素描、草稿感、紙張紋理、污漬、粗糙筆觸。禁止生成 3D 線框網格模型。畫面不得出現水印、LOGO、字幕、文字或任何額外標記。

最終畫面應為乾淨俐落的黑白建築／室內設計線稿，線條清楚，留白乾淨，構圖保持原圖一致。
```

**線稿保留**：人物輪廓、場景結構、比例關係、構圖資訊
**線稿捨棄**：顏色、噪點、壓縮痕跡、破碎細節

---

### Step 2：雙圖重建（原圖 + 線稿）

開新對話，同時上傳兩張圖，使用以下 Prompt：

```
圖一作為唯一風格錨點（Style Anchor），絕對保留其構圖、色彩、光影、材質、鏡頭語言、景深表現與整體氛圍，不得改變。

圖二作為唯一結構錨點（Structure Anchor），僅用於補充高解析度輪廓、邊緣、結構比例、細節層次與清晰度，不得繼承其顏色、光影或風格。

最終輸出必須保持圖一的視覺效果與場景設計與文字版面，同時利用圖二的高解析度結構資訊進行重建。目標是高清重製（HD Reconstruction），而非重新設計（Redesign）、風格轉換（Style Transfer）或內容生成（Content Generation）。

禁止新增、刪除、替換任何人物、物件、建築元素或場景內容。禁止改變構圖、視角、焦距、光線方向與主體位置。輸出結果必須看起來像圖一的超高解析度原始版本。
```

**圖一**（原圖）= Style Anchor：色彩、光影、氛圍
**圖二**（線稿）= Structure Anchor：乾淨輪廓、結構比例

---

## 簡易去噪（輕量替代方案）

若不想跑完整流程，在任何編輯 Prompt 尾端加上：

```
移除圖片中的噪點與不必要的高頻細節，但保持原本的線條、顏色、亮度和整體設計不變。
```

效果比線稿重建法弱，但快速方便，適合輕微劣化的情況。
