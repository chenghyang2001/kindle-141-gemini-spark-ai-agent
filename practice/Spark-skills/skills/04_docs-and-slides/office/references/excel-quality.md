# Excel（.xlsx）品質與財務模型規則

> 引擎無關的品質規則。操作語法查 `officecli-commands.md`；這裡管「怎樣才專業、零錯誤」。

## 所有 Excel 檔通則

- **專業字體**：全檔一致（Arial / Times New Roman 等），除非使用者另有指示。
- **零公式錯誤**：交付前絕不可有 `#REF!`、`#DIV/0!`、`#VALUE!`、`#N/A`、`#NAME?`。
- **保留既有範本慣例**：修改別人的檔時，完全比照原格式/樣式/慣例，不要硬套自己的標準格式。既有範本慣例永遠優先。

## 一定用公式，不要硬填算好的數字

在外面（Python）算好再把結果硬填進格子＝壞習慣；要讓試算表能隨來源資料重算。

```
✗  sheet['B10'] = 5000               # 硬填加總
✓  officecli set f.xlsx /Sheet1/B10 --prop value="=SUM(B2:B9)"
✗  sheet['C5']  = 0.15               # 硬填成長率
✓  ... --prop value="=(C4-C2)/C2"
```

officecli 內建 350+ 函式**寫入即自動運算**（含財務/統計/動態陣列），不需要外部重算工具。
總計、百分比、比率、差額——全部用公式。

## 財務模型：業界標準配色（除非使用者/範本另有規定）

| 顏色 | 用途 |
|------|------|
| **藍字** (0,0,255) | 硬輸入值、使用者會改的情境數字 |
| **黑字** (0,0,0) | 所有公式與計算 |
| **綠字** (0,128,0) | 連到同一活頁簿其他工作表的連結 |
| **紅字** (255,0,0) | 連到外部檔案的外部連結 |
| **黃底** (255,255,0) | 關鍵假設 / 需要更新的格子 |

## 數字格式標準

- **年份**：當文字字串（`"2024"` 不要 `2,024`）。
- **貨幣**：`$#,##0`；標題一定標單位（如 `Revenue ($mm)`）。
- **零**：用格式讓 0 顯示為 `-`（含百分比），如 `$#,##0;($#,##0);-`。
- **百分比**：預設 `0.0%`（一位小數）。
- **倍數**：估值倍數用 `0.0x`（EV/EBITDA、P/E）。
- **負數**：用括號 `(123)`，不要 `-123`。

## 公式建構規則

- **假設集中放**：成長率/毛利/倍數等所有假設放獨立的假設格，公式用參照不要寫死。
  用 `=B5*(1+$B$6)` 不要 `=B5*1.05`。
- **防錯**：確認參照正確、範圍沒 off-by-one、各期公式一致、邊界值（0/負/極大）測過、無非預期循環參照。
- **硬輸入要註明來源**：在旁邊或註解寫 `來源：[系統/文件], [日期], [具體出處], [URL]`。
  例：`Source: Company 10-K, FY2024, Page 45, Revenue Note, [SEC EDGAR URL]`。

## 樞紐分析 / 圖表 / 排序

- 樞紐：`officecli add data.xlsx /Sheet1 --type pivottable`（rows/cols/values/filters…，見 commands.md）。
- 圖表：officecli 支援長條/折線/圓餅/Pareto/箱型圖/走勢圖等。
- 排序：`officecli set data.xlsx /Sheet1 --prop sort="C desc" --prop sortHeader=true`（超連結/註解/條件格式會跟著列走）。

## 清理雜亂資料

畸形列、標題錯位、垃圾資料 → 重整成乾淨表格。可先 `officecli view file.xlsx text` 看內容，
或用 pandas 讀進來清洗後再輸出，最後用 officecli 補公式/格式/圖表。

## 交付前檢查

1. `officecli validate data.xlsx`。
2. 抽查 2～3 個參照值是否正確。
3. 全檔掃錯：確認沒有任何 `#REF!/#DIV0!/#VALUE!/#N/A/#NAME?`。
4. 財務模型：配色對、數字格式對、假設與公式分離。
