 書內附

上課前先裝好

這幾件事在家裡先做完，課堂上才不會卡在安裝。

1 Python
終端機輸入 winget install Python.Python.3.12，裝完關掉終端機再重開
2 FFmpeg（專案一要用）
終端機輸入 winget install Gyan.FFmpeg，一樣要重開終端機
3 MediaPipe（專案二要用）
終端機輸入 pip install mediapipe opencv-python， 這步要 5～10 分鐘，務必課前裝好
4 一把 AI 金鑰（專案三要用）
Gemini 或 Groq 都有免費額度，申請網址與設定方式書裡第 6 頁有寫
