## 這個範例示範了什麼

- **八區塊的實際篇幅比例**：①先看成果短、⑤跟著做一次最長、⑥程式碼全文照登
- **28 行分段規則**：看 `<!--G1-->`、`<!--G2-->` 怎麼切一支 159 行的程式
- **書面口吻**：全篇沒有「照著念」「這邊我們看到」這類後台字眼
- **無年份日期**：全篇掃不到任何 20XX 年、月/日（教材不能有時效感）
- **標註的力道**：紅框只框關鍵處，不是滿版塗鴉
