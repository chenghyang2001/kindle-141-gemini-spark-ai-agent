# 提問階梯：凹面鏡與凸面鏡

> 延續 `ch17/lesson-plan.md`，由淺入深 5 題。參考答案為要點，供周老師課堂使用。

| 層次 | 題目 | 參考答案要點 |
| --- | --- | --- |
| **1. 回憶** | 凹面鏡和凸面鏡的鏡面，分別是向內凹還是向外凸？ | 凹面鏡：反射面向內凹，像湯匙內側。凸面鏡：反射面向外凸，像湯匙背面。 |
| **2. 理解** | 為什麼說凹面鏡會「會聚」光線、凸面鏡會「發散」光線？ | 平行光照到凹面鏡，反射後會集中到一點（焦點）；照到凸面鏡，反射後向外散開，看起來像從鏡子後方一點散出。 |
| **3. 應用** | 路口轉角的反光鏡應該用哪一種鏡子？為什麼？ | 用凸面鏡。凸面鏡成正立、縮小的像，看到的範圍比平面鏡廣，駕駛和行人能看到轉角另一側的來車。 |
| **4. 分析** | 用湯匙內側照臉，離很近時影像正立放大，拿遠一點卻變成倒立。這是為什麼？ | 湯匙內側是凹面鏡，成像會隨距離改變：物體在焦點以內時，成正立、放大的虛像；物體在焦點以外時，成倒立的實像。距離改變，影像就跟著改變。 |
| **5. 評估** | 有同學說：「汽車後照鏡用凸面鏡比用平面鏡好，因為看得比較廣。」你同意嗎？請說出優點和要注意的地方。 | 部分同意。優點：視野較廣，能減少死角。要注意：凸面鏡的像是縮小的，物體看起來比實際遠，所以鏡子上會提醒「物體實際距離比鏡中所見更近」，判斷距離時要小心。好的回答要同時提出優點與限制。 |
