# 板書：凹面鏡與凸面鏡

> 三層樹狀結構：大標 → 小標 → 重點。每個重點 15 字內，可直接抄到黑板。

```
凹面鏡與凸面鏡
├─ 一、凹面鏡（向內凹）
│   ├─ 光線：會聚，集中到焦點
│   ├─ 近看：正立、放大的虛像
│   ├─ 遠看：倒立的實像
│   └─ 應用：化妝鏡、手電筒反射罩
├─ 二、凸面鏡（向外凸）
│   ├─ 光線：發散，向外散開
│   ├─ 成像：一定是正立、縮小虛像
│   ├─ 優點：看到的範圍比較廣
│   └─ 應用：路口反光鏡、汽車後照鏡
└─ 三、怎麼分辨
    ├─ 湯匙內側＝凹面鏡
    ├─ 湯匙背面＝凸面鏡
    └─ 影像變小又正立→凸面鏡
```

**抄寫建議：**黑板左側寫「一、凹面鏡」，右側寫「二、凸面鏡」，左右對照；「三、怎麼分辨」寫在下方中央，最後總結時再寫。
