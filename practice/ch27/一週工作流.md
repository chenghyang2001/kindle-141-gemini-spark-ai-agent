# 一週 Spark 工作流：吳老師的班級秘書

> 人物與所有情境皆為 Spark 虛構範例；本檔**沒有操作任何服務**。檔名、資料夾、學生資料一律用【佔位符】。

## 人物設定

- **吳老師**：國中數學老師，任教八年級 **4 個班**，同時擔任 **802 班導師**。
- **每週最煩的三件雜事：**
  1. 每週追作業缺交，要一班一班對名單。
  2. 每週寫家長通知與聯絡事項，常常寫到很晚。
  3. 週一學年會議的筆記很亂，會後還要整理成待辦。

## 一、週一到週五工作流表

| 星期 | 要自動化的事 | 資料來源 | 觸發時間 | 輸出位置與格式 | 權限邊界（不能做的事） | 需要人工檢查什麼 |
| --- | --- | --- | --- | --- | --- | --- |
| **週一** | 學年會議筆記 → 會議紀錄與待辦 | 【會議筆記文件】（老師會後貼上） | 老師說「整理今天的會議」時 | 【會議紀錄資料夾】／`會議紀錄_YYYY-MM-DD.md`，分決議、待辦、待討論三段 | 不寄給其他老師、不建日曆活動、不指派任務、不改原始筆記 | 負責人與期限是否正確；「待確認」項目要自己補 |
| **週二** | 4 個班的作業缺交統計 | 【作業繳交試算表】的各班分頁（唯讀） | 每週二 07:00 排程（名稱加「練習_」） | 【作業統計資料夾】／`缺交統計_YYYY-MM-DD.md`，依班級列出缺交座號與次數 | 試算表唯讀；不寄信給學生或家長；不在班群公布名單；不改繳交紀錄 | 抽查 1 個班，對照繳交表確認數字；缺交 3 次以上的名單要自己判斷是否聯絡 |
| **週三** | 802 班家長通知草稿 | 【學校行事曆】本週與下週的活動、老師口述的注意事項 | 老師說「寫這週的家長通知」時 | 存成**草稿**：【通知草稿資料夾】／`家長通知_YYYY-MM-DD.md`，200 字以內，標明「草稿，未寄出」 | 不寄出、不發到班群、不放學生姓名或成績、不自行增加活動 | 日期、時間、地點、要繳的費用逐項對回行事曆；語氣是否適合 |
| **週四** | 下週數學備課素材：練習題與配圖建議 | 【教學進度表】下週單元、【往年題庫】（唯讀） | 老師說「幫我備下週的課」時 | 【備課資料夾】／`備課_單元名稱.md`：5 題練習＋答案、配圖建議表＋授權檢查表 | 不改往年題庫；不下載或指定任何圖片；不上網抄題；不上傳學校平台 | 每題自己算一次答案；配圖要自己查授權並記下查閱日期 |
| **週五** | 802 班一週班級週報＋自己的學習追蹤 | 本週週一～週四的輸出檔、【班級動態紀錄表】（唯讀） | 每週五 15:00 排程（名稱加「練習_」） | 【週報資料夾】／`班級週報_YYYY-Www.md`：本週大事、下週提醒、待追蹤事項；另附「本週 Spark 使用紀錄」 | 不寄信、不發布、不改任何來源檔；只彙整本週已有的檔案 | 週報中每一件事都要能在來源檔找到；學生相關內容去識別化 |

## 二、七欄位指令草稿

### 週一：學年會議紀錄

| 欄位 | 內容 |
| --- | --- |
| 目標 | 把今天學年會議的筆記整理成會議紀錄，讓我知道我要做哪些事。 |
| 資料來源 | 只用我貼上的【會議筆記文件】；不讀信箱、不讀其他會議紀錄。 |
| 執行步驟 | (1) 摘要會議主題 (2) 分出決議、待辦、待討論 (3) 待辦寫成「事項／負責人／期限」 (4) 標出跟我（數學科、802 導師）有關的項目。 |
| 判斷規則 | 負責人或期限沒寫，標「待確認」，不從職稱推測；不加評論。 |
| 輸出位置與格式 | 【會議紀錄資料夾】／`會議紀錄_YYYY-MM-DD.md`，三段固定格式，第一行寫產生時間。 |
| 時間或觸發 | 我說「整理今天的會議」時執行一次。 |
| 權限邊界 | 能新建這一份紀錄；不能寄信、不能分享、不能建日曆活動、不能指派任務、不能修改原始筆記。 |

### 週二：作業缺交統計

| 欄位 | 內容 |
| --- | --- |
| 目標 | 統計 4 個班本週的作業缺交情況，讓我快速知道要追誰。 |
| 資料來源 | 只讀【作業繳交試算表】中【801】【802】【803】【804】分頁本週的欄位；不讀成績表或學生聯絡資料。 |
| 執行步驟 | (1) 回報讀到幾個分頁、幾份作業 (2) 依班級列出缺交的座號與份數 (3) 統計本學期累計缺交 3 次以上的座號 (4) 寫成統計檔。 |
| 判斷規則 | 只用座號，不寫姓名；格子空白算「未繳」，寫「補交」算已繳，其他文字列為「待確認」；分頁讀取失敗就寫「讀取失敗」，不估算。 |
| 輸出位置與格式 | 【作業統計資料夾】／`缺交統計_YYYY-MM-DD.md`，一班一張表，最後附總計與驗算。 |
| 時間或觸發 | 每週二 07:00，排程名稱「練習_作業缺交統計」。 |
| 權限邊界 | 試算表唯讀；只能新增統計檔；不能寄信、不能通知學生或家長、不能在班群公布、不能修改繳交紀錄。 |

### 週三：家長通知草稿

| 欄位 | 內容 |
| --- | --- |
| 目標 | 擬一份 802 班本週的家長通知草稿。 |
| 資料來源 | 只讀【學校行事曆】本週與下週的活動，以及我口述的【注意事項】。 |
| 執行步驟 | (1) 列出本週與下週和 802 班有關的活動 (2) 加上我口述的注意事項 (3) 依日期排序寫成通知。 |
| 判斷規則 | 行事曆沒寫的時間、地點、費用，標「待確認」，不自己補；不提到任何學生的姓名或成績；語氣親切、先講重點、200 字以內。 |
| 輸出位置與格式 | 【通知草稿資料夾】／`家長通知_YYYY-MM-DD.md`，第一行寫「草稿，未寄出」。 |
| 時間或觸發 | 我說「寫這週的家長通知」時執行一次。 |
| 權限邊界 | 只能存草稿；不能寄出、不能發到班群或聯絡簿平台、不能自行新增行事曆沒有的活動。 |

### 週四：備課素材

| 欄位 | 內容 |
| --- | --- |
| 目標 | 依下週單元，準備 5 題練習題與簡報配圖建議。 |
| 資料來源 | 只讀【教學進度表】中下週的單元名稱，以及【往年題庫】；不上網找題目。 |
| 執行步驟 | (1) 回報下週單元名稱 (2) 從往年題庫挑或改寫 5 題，由易到難 (3) 附上答案與解題步驟 (4) 列出簡報配圖建議（畫面描述＋英文關鍵字）與授權檢查表。 |
| 判斷規則 | 答案不確定的題目標「待驗算」；配圖只寫建議，不指定任何圖片或網址；不編造課本頁碼。 |
| 輸出位置與格式 | 【備課資料夾】／`備課_【單元名稱】.md`，分練習題、答案、配圖建議、授權檢查四段。 |
| 時間或觸發 | 我說「幫我備下週的課」時執行一次。 |
| 權限邊界 | 只能新建備課檔；不能修改往年題庫、不能下載或使用任何圖片、不能上傳學校平台或分享給學生。 |

### 週五：班級週報與學習追蹤

| 欄位 | 內容 |
| --- | --- |
| 目標 | 彙整本週的 802 班大事與下週提醒，並記錄我這週用 Spark 的情況。 |
| 資料來源 | 只讀本週週一～週四產出的檔案，以及【班級動態紀錄表】本週的列（唯讀）。 |
| 執行步驟 | (1) 回報讀到哪些檔案 (2) 整理本週大事 (3) 列出下週提醒與待追蹤事項 (4) 附「本週 Spark 使用紀錄」：用了哪些工作流、哪一次結果需要大幅修改。 |
| 判斷規則 | 只彙整來源檔中有的內容，不新增事件；學生一律用座號；來源檔缺少某天的，就寫「本週【星期】無資料」。 |
| 輸出位置與格式 | 【週報資料夾】／`班級週報_YYYY-Www.md`，第一行寫產生時間。 |
| 時間或觸發 | 每週五 15:00，排程名稱「練習_班級週報」。 |
| 權限邊界 | 只能新建週報檔；不能寄信、不能發布、不能修改任何來源檔或動態紀錄表。 |

## 三、要用到的技能

| 技能類別 | 用在哪裡 | 為什麼需要 | 練習時最容易出錯的地方 |
| --- | --- | --- | --- |
| **資料整理** | 週一、週二、週五 | 把雜亂的筆記與表格轉成固定格式，是每天都會用到的基本功 | 為了把表格填滿，自己補上沒寫的負責人或數字 |
| **查證** | 週三、週四 | 通知的日期地點、題目的答案，都要能對回原始資料 | 只看 Spark 說「已確認」就相信，沒有自己對照行事曆或重算答案 |
| **授權確認** | 週四 | 簡報配圖要確認能不能用、要不要標出處 | 以為「網路上找得到」就是免費可用，忘了記下查閱日期 |
| **金鑰管理** | 若之後串接外部模型 API | 金鑰外洩可能被盜用產生費用 | 把金鑰直接寫在程式或貼到聊天裡測試 |
| **模型比較** | 選擇翻譯或出題用的模型 | 不同模型在中文、數學推理上的表現不同，要選適合的 | 只問一題就下結論，或用不同的題目比較兩個模型 |
| **學習追蹤** | 週五 | 記錄哪些工作流好用、哪些常要大改，才知道下一步要調整什麼 | 只記「用了什麼」，沒記「哪裡出錯、改了什麼」 |
| **排程管理** | 週二、週五 | 固定時間自動跑，省去手動 | 排程名稱沒加「練習_」，忘了有在跑；資料表欄位改了沒暫停排程 |
| **權限設定** | 全部 | 決定 Spark 能讀什麼、能做什麼 | 為了方便一次開太多權限，或忘記關掉測試時開的權限 |

## 四、風險與把關

| # | 風險 | 可能發生的狀況 | 具體把關動作 |
| --- | --- | --- | --- |
| 1 | **幻覺／編造** | 會議紀錄出現沒講過的負責人；家長通知多了不存在的活動 | 每份輸出抽查 3 處，逐一對回原始筆記或行事曆；指令裡一律寫「沒寫就標待確認」 |
| 2 | **金鑰外洩** | 把 API 金鑰貼在程式或對話中，被別人看到後盜用 | 金鑰只放在指令碼屬性；分享程式前全文搜尋確認沒有金鑰；後台設用量上限 |
| 3 | **圖片授權** | 簡報用了不能商用或需要標出處的圖 | 每張圖填一份授權檢查表，記下查閱日期並截圖存證；不確定就換圖或自己畫 |
| 4 | **官方功能過時** | 照著舊教學操作，找不到按鈕或功能已改名 | 看教學前先確認影片日期與版本；重要功能每學期查一次官方說明並記下日期 |
| 5 | **學生個資** | 缺交名單、通知裡出現學生姓名或成績，被轉傳出去 | 所有工作流一律只用座號；不把成績表與聯絡資料開給 Spark；家長通知不提任何個別學生 |
| 6 | **自動對外送出** | Spark 直接寄信給家長或在班群發布 | 所有對外動作都只存草稿；寄信與發布權限不開給排程類工作流 |
| 7 | **排程跑錯沒人發現** | 試算表欄位改了，缺交統計數字全錯但每週照樣產出 | 每週二抽查 1 個班；欄位調整時先暫停排程；學期末刪除所有「練習_」排程 |

## 五、三週導入計畫

| 週次 | 重點 | 這週要做的事 |
| --- | --- | --- |
| **第 1 週** | **只做「手動觸發」的工作流** | 先設定常駐規則（繁中、對外動作先確認、檔案存固定位置）；試用週一會議紀錄與週三家長通知草稿，全部用虛構或已去識別化的資料 |
| **第 2 週** | **加入排程與唯讀資料** | 建立「練習_作業缺交統計」與「練習_班級週報」兩個排程；只開唯讀權限；每次結果都人工核對 |
| **第 3 週** | **備課與把關** | 試用週四備課工作流；練習授權檢查表；整理一份自己的技能清單與風險把關表，決定哪些工作流要正式使用、哪些先暫停 |

### 驗收清單

- [ ] 常駐規則已設定，並用 3 個小請求測試過規則有生效。
- [ ] 五個工作流的七欄位指令中，所有【佔位符】都換成自己的內容，沒有遺漏。
- [ ] 每個工作流至少跑過一次，並抽查 3 處對回原始資料，沒有發現編造。
- [ ] 寄件備份裡沒有任何 Spark 自動寄出的信；班群沒有任何自動發布的內容。
- [ ] 所有輸出檔都在指定資料夾，檔名有日期，沒有覆蓋舊檔。
- [ ] 兩個排程名稱都帶「練習_」，而且我知道怎麼暫停與刪除。
- [ ] 所有輸出都只用座號，沒有出現學生姓名、成績或聯絡資料。
- [ ] 備課用的每張圖都有授權檢查表與查閱日期。
- [ ] 沒有任何金鑰出現在程式、文件或對話紀錄中。
- [ ] 寫下三週的使用心得：哪個工作流最省時間、哪個最常要大改，下一步要調整什麼。
