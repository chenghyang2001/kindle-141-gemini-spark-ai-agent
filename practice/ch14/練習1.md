# 第 14 章 練習 1：請 Spark 寫 GAS 每日摘要程式

（以 Gemini Spark 身分回答；值週紀錄為虛構範例）

## 1. 虛構資料：`ch14/daily-log.csv`

12 列值週紀錄（11-16、11-17 兩天），欄位為日期（月-日文字）、時段、項目、負責人、狀態。**已完成 9 列、未完成 3 列**（已用指令統計確認）。

## 2. 程式：`ch14/sendDailyDigest.gs`

`sendDailyDigest()` 的流程：

1. 讀取目前試算表的所有資料，**跳過標題列**，並略過整列空白。
2. **用標題名稱找欄位**（不寫死第幾欄），欄位順序被調整也不會讀錯。
3. 統計總列數、已完成、未完成；狀態不是這兩種的列另外列為「狀態異常」。
4. 列出未完成清單，並**依負責人分組**統計。
5. 組成信件內文，用 `MailApp.sendEmail` 寄給 `Session.getActiveUser()` 取得的目前使用者。

錯誤處理（都用 `Logger.log` 記錄，不讓程式中斷）：

- 空表或只有標題列 → 記錄後結束，不寄空白摘要。
- 缺少必要欄位 → 記錄缺哪幾欄與目前的標題列，然後結束。
- 取不到使用者信箱 → 記錄後不寄信。
- 其他意外錯誤 → `try/catch` 記錄錯誤訊息。
- 日期欄若被試算表自動轉成日期物件，會轉回「MM-dd」文字。

另外加了 `DRY_RUN` 開關：設成 `true` 時只把內文印在執行紀錄，不寄信，方便測試。每個重要步驟都用繁體中文註解說明「為什麼」這樣做。

## 3. 檔案頂端註解

- **貼進 Apps Script 的步驟**：匯入 CSV（先把日期欄設為純文字）→ 擴充功能 → Apps Script → 貼上儲存 → 選 sendDailyDigest 執行。
- **第一次執行的授權提示**：需要授權 → 審查權限 → 選帳號 →「Google 尚未驗證這個應用程式」→ 進階 → 前往（不安全）→ 允許兩項權限（試算表、以你的身分寄信）。
