## 第二步：讀發票規則

1. 讀不出來就先留白，並告訴我是哪一張，不要自己編。
2. 不要編造店家、品項、發票號碼。
3. 只存草稿、不寄信。
4. （補充）類別只看「看得清楚的字」來判斷；連類別都判斷不了，就一起留白。
5. （補充）金額讀得清楚就照記，但整張發票標成「待確認」。

**要請你補的資料：**發票 B 的完整店名、發票 D 的完整品項（例如是哪種房型，或有沒有含早餐）。

## 第四步：小計與總計

| 類別 | 計算 | 小計 |
| --- | --- | ---: |
| 辦公用品 | 385 | 385 |
| 餐飲 | 270 | 270 |
| 交通 | 320 | 320 |
| 住宿 | 2,400 | 2,400 |
| **總計** | 385 + 270 + 320 + 2,400 | **3,375** |

- 已完成、可以直接報帳：385 + 320 = **705**
- 待確認（金額已計入，但資料還要補）：270 + 2,400 = **2,670**
- 驗算：705 + 2,670 = 3,375 ✔

## 如果沒有那三句防猜規則，最可能出錯的欄位

**最可能出錯的是「店家」欄（發票 B）。**「好[?]咖啡」看起來很像常見的店名，AI 很容易「順手」補一個字，表格看起來很完整，反而沒人會發現。店家名稱錯了，會計拿去和統一編號、發票號碼核對時對不上，整筆報帳會被退回，甚至可能被當成不實報帳。
排第二的是發票 D 的「品項」：被遮住的地方很容易被補成「雙人房」之類的字，這會影響可不可以報帳（例如公司差旅規定只能報單人房）。
