# 課程練習：雲端排程設定單（給 Claude Code 控制台 Routines 用）

> ⚠️ 練習格**沒有**建立這個排程。請自己到 claude.ai/code 的排程（Routines）頁面照下表填寫。

## 一、基本設定

| 欄位 | 填寫內容 |
| --- | --- |
| 排程名稱 | 課程練習_每月報帳檢查 |
| 執行時間 | 每月 28 日 09:00（台北時間） |
| cron | `0 9 28 * *`（時區選 Asia/Taipei）；若控制台只吃 UTC，改填 `0 1 28 * *` |
| 為什麼 28 日 | 每個月（含 2 月）都有 28 日，且離月底還有幾天可補單據 |
| 程式庫 | 放有 `practice/ch11/expenses.csv` 的 repo（唯讀使用） |
| 連接器 | **Gmail**（只用「建立草稿」）；不加 Google 日曆、雲端硬碟或其他連接器 |
| 允許的工具 | 讀檔（Read）、Gmail 建立草稿；不允許寫檔、git push、寄信 |

## 二、完整提示詞（整段貼進排程）

```text
你是「課程練習_每月報帳檢查」排程。請依下列規則執行，不要問問題。

【權限邊界】
- 只讀取 practice/ch11/expenses.csv，唯讀：不修改、不刪除、不排序、不補任何欄位，也不 commit、不 push。
- 不寄信、不回覆任何信件、不發訊息、不送出報帳申請。
- 唯一允許的寫入動作：用 Gmail 連接器建立「一封草稿」，收件人留空。

【步驟】
1. 記下執行時間（台北時間，格式 YYYY-MM-DD HH:mm）。
2. 讀取 CSV，篩出日期屬於「本月」的列。
3. 依「類別」計算筆數與金額小計，再算合計，附驗算式；另列「完成」與「待確認」的金額。
4. 列出待處理清單：任何欄位留白、或狀態為「待確認」的列，寫出編號、欄位、備註。
5. 金額留白或不是數字的列不算進小計，改列入待處理清單。本月沒有資料就寫「本月無報帳資料」，不要產出 0 元報表。
6. 不猜、不補、不編造任何店家、品項、金額或發票號碼。

【輸出】
- 建立 Gmail 草稿，主旨：「課程練習｜報帳月報 YYYY-MM｜執行於 YYYYMMDD-HHmm」。
- 內文第一行：「執行時間：YYYY-MM-DD HH:mm（台北）；資料來源：practice/ch11/expenses.csv」。
- 內文依序：月報摘要表、待處理清單、最後一行「本次未寄信、未修改任何資料」。
- 結束時在執行紀錄回報草稿主旨與草稿 ID。
```

## 三、驗收步驟

1. 在控制台按「立即執行」一次（不必等到 28 日）。
2. 看執行紀錄：沒有錯誤，且有回報草稿主旨與 ID。
3. 到 Gmail「草稿」：有 1 封主旨以「課程練習」開頭、含執行時間戳的草稿。
4. 核對內容：合計 3,375、4 筆；待處理清單列出編號 2（店家）與編號 4（品項）。
5. 到 Gmail「寄件備份」：沒有任何新寄出的信。
6. 確認 `expenses.csv` 與 repo 沒有新 commit、內容沒被改。
7. 把草稿 ID 記到 `ch11/cleanup.md`。

## 四、驗收後要刪除

1. 驗收通過後，**到排程頁面刪除「課程練習_每月報帳檢查」**（練習用，不留著自動跑）。
2. 刪除這次產生的「課程練習｜報帳月報…」草稿。
3. 在 `ch11/cleanup.md` 註記「排程已刪除、草稿已刪除」與日期。
4. 要正式使用時，另建不含「課程練習」的正式排程，資料改指向正式報帳檔。
