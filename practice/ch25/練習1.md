## 2. Apps Script 呼叫草稿（未執行）

- 金鑰、端點、模型名稱都從**指令碼屬性**讀取（`AI_API_KEY` 的值在專案設定中填【YOUR_KEY】），缺哪一項就回報哪一項。
- 設定 `max_tokens`（常數 `DEFAULT_MAX_TOKENS`，並註明中文要預留空間）。
- 用 `muteHttpExceptions` 自己判斷狀態碼：401／403、429、其他錯誤各有可讀訊息。
- **檢查結束原因**：`length` 時區分「內容是空的」與「被截斷」，提示調高上限或縮短輸入；內容空白也不當成成功。
- 程式中沒有任何金鑰字串（已抽出程式碼用 `node --check` 檢查語法，並搜尋確認沒有金鑰字樣）。

## 3. 排錯速查：內容空白＋結束原因 length

- **原因**：碰到 `max_tokens` 上限被截斷；思考過程先用光額度，或輸入太長擠掉輸出空間。
- **處理**：調高上限、縮短輸入或分批、要求精簡回答、調低思考強度、程式一定檢查結束原因。
- **中文要開更大**：模型以 token 計算，中文常常一個字就要一個以上 token，同樣上限能寫的中文比英文少很多。

## 4. 金鑰安全檢查表（6 條）

1. 程式與文件中沒有金鑰本體，只用指令碼屬性。
2. 不貼到聊天、Email、截圖、公開 GitHub。
3. 錯誤訊息與紀錄不印出金鑰。
4. 後台設定用量上限或預算提醒。
5. 每個專案用獨立金鑰，不用就停用。
6. 懷疑外洩立刻撤銷、重新產生，並檢查用量。
