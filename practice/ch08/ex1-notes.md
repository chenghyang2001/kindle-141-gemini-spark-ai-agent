## 補充的部分

- frontmatter：`name`（小寫連字號）、`description` 列 7 種口語觸發說法＋不觸發情境——原提示詞沒有，這是 Claude 判斷何時自動啟用的依據。
- 固定輸出模板（待辦用表格）與一個輸入／輸出範例，讓格式穩定。
- 規則 6～10：忠於原文、未定案歸第三段、相對日期不換算、空段寫「（無）」、繁體中文。

## 放進 git 的好處

- 技能跟專案一起走：clone 下來就有，團隊成員共用同一份規則。
- 有版本歷史：改壞規則可 diff、可回復，知道是誰為什麼改。
- 可走 PR 審查：規則變更像程式碼一樣被檢查。
- 不綁平台帳號：不像在網頁 AI 裡調的提示詞，換工具或換機器就遺失。
