## 4. 建立與刪除該用不同程度的確認

建立錯了可以再刪（可逆）；刪除錯了資料就不見（難逆），所以確認強度要不同：

| 動作 | 確認程度 | 做法 |
| --- | --- | --- |
| 建立 | 輕度 | 列出「準備建立」清單，批次一次確認；標題加「課程練習」前綴方便日後清理 |
| 修改 | 中度 | 列「改前 → 改後」對照，逐筆確認 |
| 刪除 | 重度 | 先 list 拿到真實 ID → 判斷依據寫出來 → 符合筆數 ≠ 預期就停 → 確認框列「完整標題＋ID」、預設跳過 → 一次只刪一筆 → 刪後再 list 核對筆數 |
