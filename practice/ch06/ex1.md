# 排程設計單：每日報名摘要

> 情境：某登山社「秋季合歡山健行」活動的報名紀錄。社團、人名與資料全部為 Spark 虛構範例。

## 示意資料：活動報名紀錄（試算表「練習_活動報名紀錄」）

| 編號 | 報名時間 | 姓名 | 繳費狀態 |
| --- | --- | --- | --- |
| R01 | 2026-11-12 10:20 | 王小華 | 已繳 |
| R02 | 2026-11-12 19:05 | 李美君 | 未繳 |
| R03 | 2026-11-14 21:30 | 陳建國 | 已繳 |
| R04 | 2026-11-15 08:15 | 林佳慧 | 未繳 |
| R05 | 2026-11-15 13:40 | 張志明 | 已繳 |
| R06 | 2026-11-15 22:10 | 黃怡婷 | 未繳 |

## 1. 排程名稱

**練習_每日報名摘要**

## 2. 執行時間

**每天 07:00（台北時間，UTC+8）**，每天執行一次。

## 3. 使用說明（七欄位指令）

| 欄位 | 指令內容 |
| --- | --- |
| **目標** | 每天早上產出一份報名摘要，讓幹部一眼看到：新增報名人數、已繳費人數、待跟進人數。 |
| **資料來源** | 只讀取試算表「練習_活動報名紀錄」的「編號、報名時間、姓名、繳費狀態」四欄；不讀其他檔案、信件，也不上網。 |
| **執行步驟** | (1) 讀取紀錄表全部資料 (2) 統計**新增報名**：報名時間在「前一天 07:00 到今天 07:00」之間的筆數 (3) 統計**已繳費**：繳費狀態為「已繳」的總人數 (4) 找出**待跟進**：繳費狀態為「未繳」且報名已超過 3 天的人 (5) 把結果寫成摘要檔 |
| **判斷規則** | 只依表格裡的資料計算，不推測、不補資料；繳費狀態不是「已繳」或「未繳」的列，計入「資料異常」並列出編號；找不到紀錄表或讀取失敗時，不產出數字，改寫一份「執行失敗」說明。 |
| **輸出位置與格式** | 固定存到 Google Drive「`練習_每日摘要/`」資料夾；檔名 `每日摘要_YYYY-MM-DD_0700.md`；每天一個新檔，**不覆蓋舊檔**；檔案第一行寫「執行時間：YYYY-MM-DD HH:MM（UTC+8）」與「資料讀取時間」。 |
| **時間或觸發** | 每天 07:00 自動執行一次；不在其他時間觸發，也不因為資料變動而觸發。 |
| **權限邊界** | 紀錄表只讀不寫（不修改、不排序、不刪除任何列）；不寄信、不發訊息、不催繳；只能在「練習_每日摘要/」資料夾裡新增檔案，不動其他資料夾。 |

### 輸出示意（假設 2026-11-16 07:00 執行）

```markdown
執行時間：2026-11-16 07:00（UTC+8）｜資料讀取時間：2026-11-16 07:00
資料來源：練習_活動報名紀錄（共 6 筆）

- 新增報名：3 人（R04 林佳慧、R05 張志明、R06 黃怡婷）
- 已繳費：3 人（R01、R03、R05）
- 待跟進：1 人（R02 李美君，報名已 3 天半仍未繳）
- 資料異常：0 筆
```

> 為什麼 R04、R06 未繳卻不算待跟進：他們報名還不到 3 天，先給繳費的緩衝時間。

## 4. 三原則對照

| 指令內容 | 落實的原則 |
| --- | --- |
| 紀錄表只讀不寫，不修改、不排序、不刪除任何列 | **能唯讀就唯讀** |
| 只讀需要的四個欄位，不讀其他檔案與信件 | **能唯讀就唯讀** |
| 不寄信、不發訊息、不催繳（只產出名單，由人決定要不要聯絡） | **能唯讀就唯讀** |
| 固定存到「練習_每日摘要/」資料夾，不動其他資料夾 | **產出放固定位置** |
| 檔名格式固定為 `每日摘要_YYYY-MM-DD_0700.md` | **產出放固定位置**＋**要留時間戳** |
| 每天一個新檔、不覆蓋舊檔 | **要留時間戳**（每天的結果都能回頭比對） |
| 檔案第一行寫執行時間與資料讀取時間 | **要留時間戳** |
| 讀取失敗時寫「執行失敗」說明，而不是空白或猜數字 | **要留時間戳**（也有固定位置可查哪天出錯） |

## 5. 怎麼關掉

**暫停（可以隨時恢復）：**

1. 開啟 Spark 的「排程」清單。
2. 找到「練習_每日報名摘要」。
3. 按「暫停」，確認狀態變成「已暫停」。
4. 隔天 07:00 之後到「練習_每日摘要/」確認**沒有**新檔案產生。

**刪除（無法復原）：**

1. 先暫停，確認沒有問題。
2. 在排程清單選「練習_每日報名摘要」→「刪除」→ 確認名稱無誤後再按確認。
3. 刪除排程**不會**刪掉已產出的摘要檔；不需要的話，請自行到資料夾整理。

**什麼情況下你該暫停它：**

- 活動已截止報名，不需要每天統計了。
- 紀錄表的欄位改名、移動或換檔案（排程可能讀錯欄位）。
- 連續兩天出現「執行失敗」或「資料異常」。
- 摘要數字跟你手動算的不一樣。
- 長假期間不會有人看摘要。
