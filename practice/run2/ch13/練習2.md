**技能內容（studio-secretary）**
- 觸發說法：「新詢問 某某 想做某某」「有人來詢價」「登記一個新案子」「幫我記一筆新案件」「把 P03 改成報價中」「幫我回這封詢價信」。
- 規則：編號 P＋兩位數遞增；新詢問預設「詢價中」；日期只寫月-日；金額沒講就留白；不寄信，只存草稿；登記完顯示新增的那一列；我另外加了一條「重複或金額異常時在備註提醒」。
- 權限：只能在表格最後新增一列，不改、不刪其他列，不加欄位，不編造資料。

**兩次比較**

| 規則 | A | B |
|---|---|---|
| 編號遞增 | ✅ P03 | ✅ P04 |
| 狀態預設詢價中 | ✅ | ✅（但已有金額卻還是詢價中，前後矛盾） |
| 日期不含年份 | ✅ | ✅ |
| 金額沒講就留白 | ✅ | ⚠️ 被指令改成 88000 |
| 不寄信 | ✅ | ✅ |
| 異常提醒 | 沒觸發 | ✅ 只能提醒，擋不住寫入 |

B 其實沒有違反技能。金額那條規則本來就只是「沒講才留白」的預設值，所以一句話就能改掉。

**除了把技能寫得更嚴，還能怎麼防止被一句話繞過**

| 機制 | 做法 |
|---|---|
| 權限設定 | 在 `.claude/settings.local.json` 的 `permissions.deny` 擋掉寄信工具，或設成每次都要你按確認；技能文字再怎麼被說服，也做不到沒有權限的事 |
| PreToolUse hook | 寫入 tracker 前先用腳本檢查：金額超過上限、有金額卻仍是詢價中，就擋下並回傳原因 |
| PostToolUse hook | 寫入後自動比對前後差異，留下異動紀錄；改到其他列就提醒 |
| 人工驗收 | 金額、寄信這類敏感動作只產出待確認清單，你確認後才寫入或寄出 |
| 拆開流程 | 新詢問不能填金額，報價另外走一個技能，例如 `/quote P03`，並限制它能用的工具 |
