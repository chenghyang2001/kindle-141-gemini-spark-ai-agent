**搬到別台電腦或別的 AI**
| 情境 | 做法 | 要改嗎 |
|---|---|---|
| 整個 practice 資料夾複製到另一台的 Claude Code | 在那個資料夾裡啟動 `claude`，技能放在專案的 `.claude/skills/` 底下，會自動載入 | 不用 |
| 想在所有專案都能用 | 把技能資料夾複製到 `~/.claude/skills/` | 不用 |
| 其他支援技能的 AI | 把技能資料夾放進該平台的技能目錄，或打包成 zip 上傳 | 大多不用改 |

如果換到其他 AI，建議檢查這幾點：
- 資料夾名稱要和 `name` 欄位一樣，目前兩者一致。
- `version`、`source` 不是標準欄位。Claude Code 會略過；比較嚴格的平台可能跳警告，可以把它們移到 `metadata:` 底下。
- `description` 有字數上限，大約 1024 字元，目前沒有超過。
- 如果對方用英文判斷什麼時候啟動技能，可以在 `description` 補上 `meeting notes`、`minutes` 這類英文關鍵字。
- 這個技能只整理文字、不用任何連接器，所以不用另外設定權限。
