# 學生作業繳交自動化 — 上課操作步驟

> 一節課（約 45 分鐘）可完成。做完學員會有：
> 表單能收作業 → 檔案自動改名歸檔到雲端硬碟 → 試算表自動記錄 → 學生自動收到通知信。

---

## 開始之前先講的一句話

> 「等一下我們要用程式寄 Gmail。你會不會想說：是不是要去申請什麼 API 金鑰、什麼憑證？
> **完全不用。** 因為這支程式就住在你的 Google 帳號裡面，它的身分就是你。」

（這句先講，可以省掉後面一半的疑問。）

---

## 第一步：建表單（約 8 分鐘）

1. 到 <https://forms.new> 建一份新表單，命名為「○○作業繳交」。
2. 依序加這五題，**題目文字要跟下表一致**（程式是照題目名字抓答案的）：

| 題目 | 題型 | 必填 |
|---|---|---|
| 姓名 | 簡答 | ✅ |
| 班級 | 簡答（或下拉選單） | ✅ |
| 座號 | 簡答 | ✅ |
| 作業名稱 | 簡答（或下拉選單） | ✅ |
| 電子郵件 | 簡答 | ✅ |
| （檔案上傳） | **檔案上傳** | ✅ |

> **題目名稱可以換嗎？** 可以。程式支援替代名稱：
> 姓名／學生姓名、班級／班別、座號／學號、作業名稱／作品名稱／主題、電子郵件／Email。
> 要用其他名稱，改 `CONFIG.FIELDS` 就好。

3. 加「檔案上傳」題時 Google 會跳警告說填答者必須登入，按**繼續**。

> ⚠️ **這一點一定要跟學員講清楚**
> 表單的「檔案上傳」題**強制要求填答者登入 Google 帳號**，
> 而且檔案會存進**表單擁有者（老師你）**的雲端硬碟、佔你的空間。
> 校內學生有帳號沒問題；校外人士要免登入繳件，表單做不到。

4. 上方「**回覆**」分頁 → 按綠色試算表圖示 → **建立新試算表**。

---

## 第二步：建歸檔資料夾（約 2 分鐘）

1. 到雲端硬碟建一個資料夾，例如「**作業歸檔區**」。
2. 打開它，從網址列複製 ID：

```
https://drive.google.com/drive/folders/1zOiIltAYE3KencnUvVwqToRQYkYpbyvV
                                       └──────── 這一段就是 ID ────────┘
```

---

## 第三步：貼程式（約 5 分鐘）

1. **從剛剛那張試算表**點「**擴充功能 → Apps Script**」。

   > ⚠️ 一定要從試算表開，**不要另外建獨立專案**。
   > 等一下裝觸發器要用到這個綁定關係。

2. 把預設的 `myFunction` 那幾行刪掉，貼上 `HomeworkIntake.gs` 全部內容。
3. 改最上面 `CONFIG` 區塊：

```javascript
const CONFIG = {
  ARCHIVE_FOLDER_ID: '貼上你剛剛複製的資料夾 ID',
  SCHOOL_YEAR: '2026',
  SENDER_NAME: 'OO 高中教務處',   // 改成你的學校
  SEND_MAIL: true,                // 示範時想先不寄信就改 false
  ...
};
```

4. 按 💾 儲存。

---

## 第四步：授權（約 5 分鐘，**最容易卡的一步**）

1. 函式下拉選 **`RUN_檢查設定`** → 按 **執行**。
2. 跳出「需要授權」→ **審查權限** → 選你的帳號。
3. 出現 **「Google 尚未驗證這個應用程式」**：
   - 點左下角 **「進階」**
   - 點 **「前往〔專案名稱〕（不安全）」**
   - 點 **「允許」**

> 💡 **這個紅字畫面一定要先講**
> 「這是因為程式沒送去 Google 審查。**你自己寫、只給自己用的程式，全部都長這樣。**」
> 不先講，會有一半的學員卡在這頁不敢按。**建議直接投影幕操作一次給他們看。**

4. 看執行記錄，五項全部 `[通過]` 才往下：

```
【檢查一】設定值
  [通過] 雲端硬碟歸檔資料夾　→ 作業歸檔區
  [通過] 目前的試算表　→ ○○作業繳交 (回覆)

【檢查二】寄信權限與配額
  [通過] 自己的信箱　→ teacher@school.edu.tw
  [通過] 今日剩餘寄信配額　→ 100 封（一般 Gmail 上限 100、學校 Workspace 1500）

【檢查三】表單是否已連結到這張試算表
  [通過] 表單連結狀態　→ 已連結

──────────────────────────────────────
  結果：5 項通過，0 項失敗
  設定正確，接著執行 RUN_寄測試信()。
```

---

## 第五步：測試寄信（約 3 分鐘）

執行 **`RUN_寄測試信`** → 去自己信箱看信長什麼樣子。

**先做這步再裝觸發器**，確認信件格式滿意再繼續，不然改一次就要重寄一次。

---

## 第六步：裝觸發器並實測（約 10 分鐘）

1. 執行 **`RUN_安裝觸發器`**（重複執行不會裝出兩個，會先清舊的）。
2. 打開表單，用學生的角度**真的送一筆**，附一個檔案。
3. 等 10～20 秒，**三個地方同時檢查**：

```
□ 雲端硬碟出現   作業歸檔區 / 2026 / 301 /
□ 檔名變成       2026_301_05_王小明_第三次程式作業.pdf
□ 試算表「繳交紀錄」多一列，狀態欄寫「已歸檔」
□ 學生信箱收到「【繳交成功】第三次程式作業 — 2026 學年度」
```

---

## 學員最常卡的五個地方

| 症狀 | 原因 | 怎麼修 |
|---|---|---|
| 表單送出了，什麼都沒發生 | 觸發器沒裝，或裝在表單那邊 | 執行 `RUN_安裝觸發器`；左側「觸發器」確認來源是試算表 |
| 試算表有寫、信沒收到 | 表單題目名稱對不上，抓不到信箱 | 改表單題目，或改 `CONFIG.FIELDS.email` |
| `Cannot read properties of undefined` | 手動按執行 `onFormSubmit` | **這支不能手動執行**，要從表單送一筆才有 `e` |
| 檔案沒改名 | 資料夾 ID 填錯或沒權限 | 重跑 `RUN_檢查設定` |
| 信進垃圾郵件 | 主旨像廣告、短時間寄太多 | 請學生把寄件者加入聯絡人 |

> **學員說「沒反應」時，第一件事**：叫他打開 Apps Script 左側「**執行項目**」。
> 每一次觸發的成功／失敗／花幾秒／Log 印什麼，全部都在那裡。

---

## 寄信配額（會真的撞到）

| 帳號類型 | 每日上限 | 一班 35 人可跑幾次 |
|---|---|---|
| 一般 Gmail（`@gmail.com`） | **100 封** | 約 2 次 |
| Google Workspace（學校信箱） | **1,500 封** | 約 42 次 |

- 算的是**收件人數**不是寄幾次。
- **不是午夜重置**，是滾動 24 小時。
- **建議用學校 Workspace 帳號做**，額度 15 倍，也不影響私人信箱。

---

## 補救工具

觸發器裝好之前已經有人交了，或某一筆失敗要重跑：

執行 **`RUN_補跑最後一筆`** → 會抓表單最後一筆回覆重新跑一次完整流程。

---

## 延伸練習（時間有多的話）

1. **改檔名規則**：把 `archiveFile()` 裡 `parts` 陣列的順序調換，看檔名怎麼變。
2. **改資料夾分層**：現在是「學年度／班級」，改成「學年度／作業名稱／班級」。
3. **加逾期判斷**：比對繳交時間與截止日，逾期的在試算表標紅字、信件加註「逾期繳交」。
4. **加統計**：寫一支 `RUN_統計繳交率()`，算每班交了幾人、誰還沒交。
