# 爬蟲法律與道德守則（必讀）

> 本技能整合的工具都很強大，**反偵測能力 ≠ 任意使用授權**。本頁列出每次爬取前必走的檢查表。

---

## 黃金五條

1. **先看 robots.txt**：`https://網站/robots.txt`，明確 disallow 的路徑就是不抓。
2. **先讀 ToS**：服務條款常有「禁止自動化擷取」條款；商用更要檢查 API 商業授權。
3. **不抓個資 / 隱私資料**：姓名 + 聯絡方式組合、健康紀錄、未成年資訊一律不抓。
4. **節流**：請求頻率不超過該站正常使用者的 5–10 倍。預設 `download_delay=1.0`（秒）。
5. **可識別**：自定 `User-Agent` 標明用途與聯絡 email，方便對方有事找你協調而非直接封鎖。

## 紅燈：以下情境**絕不**用本技能

- ❌ 爬付費內容後再轉發（盜版書籍、論文、線上課程影片）。
- ❌ 大量抓取個人資料用於行銷、騷擾、人肉搜索。
- ❌ 違反「禁止反向工程」條款的競業情報蒐集。
- ❌ DDoS 風險級別的高頻請求（每秒上百次）。
- ❌ 偽造身份登入他人帳號。
- ❌ 抓取受 CAPTCHA / 反爬蟲保護的「明示拒絕爬取」站點，並繞過保護。

---

## 關於 `--solve-captcha`（自動解碼）的特別界線

技能提供 `--solve-captcha`（接 NopeCHA / 2captcha）能力，但**它不改變上面第 24 條紅線**：

- ✅ 可用：解**自家網站**的 CAPTCHA（測試自己的 Turnstile/reCAPTCHA 流程）、已**書面授權**的滲透測試靶標、無障礙輔助、ToS 明確允許的場景。
- ❌ 不可用：對**第三方網站**繞過它刻意設下的 CAPTCHA 來抓內容/建帳號/搶資源——CAPTCHA 就是對方明示「不要機器人」，繞過它而沒有授權，就是踩紅線。
- 預設**關閉**，要明確 `--solve-captcha` 才啟用，且需自備付費金鑰——這個摩擦是故意的，逼你停下來想一次「我有沒有資格解這題」。

> 一句話：解碼服務是用來「驗證自己擋得對不對」，不是用來「攻破別人擋得對不對」。

## 黃燈：要先確認

- ⚠️ 商用情境（營利分析、產品比價、競品監控） → 找對方授權或用官方 API。
- ⚠️ 學術研究 → 投稿前確認可重現範圍與資料引用合規（IRB 倫理審查）。
- ⚠️ 教學素材 → 保留來源與引用，不重新發布原文（合理使用）。
- ⚠️ 公部門開放資料 → 用 [data.gov.tw](https://data.gov.tw) 等平台優先；非開放資料須申請。

---

## 綠燈：可以放心用

- ✅ 自家網站／自家系統的測試與監控。
- ✅ 公開無保護機制、明示歡迎索引（含 sitemap.xml）的內容。
- ✅ 學術引用（短摘錄、附來源、非商用）。
- ✅ CTF、HackTheBox、TryHackMe 等授權靶機。
- ✅ 教師備課自用（用來生成教材，不重新發布）。

## 違規後果（提醒用）

- 個資法（台灣）：抓取與處理個資需告知與同意，違者最高罰 2,000 萬元。
- 著作權法：未經授權重製/公開傳輸他人著作。
- 民事：對方可主張不當得利、契約違反（ToS）、商業利益損失。
- 平台帳號封鎖：IP / 帳號 / API Key 永久 ban。

## 結論

> **能爬不代表該爬**。這個技能讓你「技術上做得到」，但「法律與道德上是否該做」永遠是你自己的判斷。先問三個問題再動手：
>
> 1. 對方明示禁止了嗎？（ToS / robots.txt）
> 2. 我會傷到誰？（隱私、商業利益、對方伺服器）
> 3. 同樣目的有沒有更合規的方法？（官方 API、開放資料、人工抄）
