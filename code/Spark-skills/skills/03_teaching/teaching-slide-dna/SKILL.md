# 阿亮老師教學簡報黃金樣板（DNA）

做「翻頁式教學簡報」時，**直接套用本技能的 DNA 規格**，不要從零設計，確保系列一致。

## 快速用法
1. 讀 `references/DNA.md` 取得完整 CSS / JS / 版型元件 / 講稿格式。
2. 複製 CSS 進 `<style>`、JS 進 body 末（骨架勿改）。
3. 每個 `<section class="slide">` 一頁；第一頁加 `active`。
4. **每頁必放三件**：`.say`🎤 阿亮老師講稿卡（好念）、`pre`📋 複製區（好實做）、`.steps` 編號步驟（好教）。
5. ≥16 頁，鋪：封面→先看成果→為什麼學→帶著做多步→卡關→下載→🔧Codex/Antigravity 改→檢核→結尾。
6. 另出 `CHxx講播稿.md`（逐頁照念稿＋🖥️螢幕動作＋⌨️學員一起貼的指令）。

## 核心 DNA（摘要）
- 風格：暖米紙質背景 + 2px 黑框 + 虛線內框 + 位移實心投影，繪圖筆觸卡片風。
- 色票：`--ink:#2b2620 --accent:#d0568a --accent2:#2f8f83 --yellow:#f0c04a --blue:#5b7bd6 --shadow:rgba(60,45,25,.14)`。
- 版型元件：`.kicker`旋轉標籤 `.cards`卡 `.say`講稿 `.do`實作 `pre+.copy`複製 `.steps`步驟 `.warn`卡關 `.checklist`檢核 `.route2`雙欄 `.topnav`導覽 `.dots`圓點 鍵盤←→翻頁 `.nextch`下一章。
- 鐵律：繁中台灣用語、不寫版本號/時間預估、截圖真實（雲端用示意標「示意」）、金鑰不進散布檔、頁尾放作者卡+授權。

完整規格見 `references/DNA.md`。
