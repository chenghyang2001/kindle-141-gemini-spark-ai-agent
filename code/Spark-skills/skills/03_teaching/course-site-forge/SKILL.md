# course-site-forge：規格化教材 → mini 課程站

## 這支 SKILL 做什麼

讀一份「課程內容規格化文件」（CH41 格式），輸出一個免伺服器、瀏覽器直接開的 mini 課程站：

- `index.html`：課程總覽首頁——每章一張手繪風卡片，含章號徽章、章名、簡介、難度星等（依指令量 1–3 星）、頁數與指令數膠囊、「開始上課 ▶」＋「⬇ 下載」雙按鈕。
- `chNN.html`：每章一份可翻頁教學簡報——章封面＋每個 H3 一頁；翻頁按鈕、鍵盤左右鍵、進度圓點、指令複製鈕、末頁「下一章」浮動鈕（章與章自動串接，最後一章回首頁）。
- 視覺完全沿用課程「卡片手繪風」設計 DNA（見 `references/設計DNA規格書.md`）：墨線框、硬陰影、虛線內框、橘綠黃藍色票。

## 輸入格式（CH41 規格化 md，缺一不可）

| 語法 | 意義 | 落到哪個元件 |
|---|---|---|
| `# 標題` | 篇（整站標題） | index 大標＋簡報 `.foot` |
| `## CHxx 章名` | 章（一章一份簡報） | 章節卡片＋`chNN.html` |
| `### 頁標題` | 頁（一頁一張投影片） | `.slide` 的 `h2` |
| `【講稿】` | 老師照唸的話 | `.say` 講稿框 |
| `【指令】`＋``` 圍欄 | 學員複製執行的指令 | `.do`＋`pre`＋複製鈕 |
| `【截圖位】` | 之後放真實截圖的位置說明 | `.shotbox` 斜紋占位框 |
| `【下載】` | 該頁提供的下載檔說明 | `.dlbox` 下載說明框 |

規則：標記單獨成行；圍欄內的 `#` 一律視為程式註解不是標題；`>` 開頭的檔頭引言不進頁面。

## 處理流程

1. 讀輸入 md，依 H1／H2／H3＋四標記解析成「篇→章→頁→區塊」樹（`parse_spec`）。
2. 讀 `assets/範本_教學簡報.html`（卡片手繪風 DNA 範本，占位符 `{{CHAPTER_TITLE}}`／`{{SITE_TITLE}}`／`{{SLIDES}}`／`{{NEXT_URL}}`／`{{NEXT_LABEL}}`）。
3. 每章：生成章封面＋逐頁渲染四種區塊 → 寫出 `chNN.html`；章與章的「下一章鈕」自動串接。
4. 統計每章指令數 → 難度星等（≤2 段一星、3–4 段兩星、≥5 段三星）→ 生成 `index.html` 章節卡片。
5. 回報站名、章數、頁數與輸出清單；exit code 0 才算成功。

## 使用方式

```powershell
python scripts/build_site.py <輸入規格化.md> <輸出資料夾>
```

不帶參數＝跑 CH45 內建示範（CH41 完整範例 → `示範輸出_開放資料入門站`）；**僅限在 CH45 章資料夾（下載包解壓結構）內執行**——技能單獨裝進 skills 目錄後沒有範例資料，請一律帶兩個參數。

## 驗收標準（跑完必查）

1. 輸出資料夾有 `index.html`＋每章一個 `chNN.html`，數量＝H2 數。
2. 每份簡報頁數＝該章 H3 數＋1（章封面）。
3. 瀏覽器開啟：翻頁、鍵盤、進度圓點、複製鈕可用；Console 錯誤 0。
4. index 每張卡片的「開始上課 ▶」連得到對應章；末章「下一章鈕」回首頁。
5. 四種標記各自落在正確元件（.say／.do／.shotbox／.dlbox），中文無亂碼（全程 UTF-8）。

## 檔案結構

```
course-site-forge/
├── SKILL.md                    ← 本檔
├── assets/範本_教學簡報.html    ← 卡片手繪風簡報範本（DNA 載體）
├── references/設計DNA規格書.md  ← 色票／字體／元件規格（抄自 CH42）
└── scripts/build_site.py       ← 生成引擎
```
