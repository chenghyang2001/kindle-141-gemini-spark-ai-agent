## 一、外部 API 類

### 1. LLM 的「思考預算」會吃掉輸出額度 ⚠️ 最要命

實測（Gemini 3.5 flash，寫社群貼文）：

| 設定 | finishReason | 草稿吃掉 | 真正的答案 | 結果 |
|---|---|---|---|---|
| `maxOutputTokens: 800` | **MAX_TOKENS** | **766** | **30** | 貼文從句子中間被切斷 |
| `maxOutputTokens: 2000` | STOP | 685 | 136 | 完整，但慢又貴 |
| `800` + `thinkingBudget: 0` | STOP | — | **154** | ✅ 完整、快、便宜 |

**解法**：不需要深度推理的任務（翻譯、寫文案、下評語）一律
`thinkingConfig: { thinkingBudget: 0 }`，額度全留給要寫的內容。

> 這條**離線測試抓不到**（假的 API 不會打草稿）。

### 2. reply token 有時效

LINE 的 replyToken 約 **30 秒**。耗時處理（影像辨識、長文評閱）很容易超過。

**解法**：先回一則「處理中」，再用 push message 回結果。

### 3. 錯誤訊息要翻成中文

400/403/429/500、安全機制擋下、空白回應，各自要有中文說明。
**學員看到的永遠該是中文，不是英文 JSON。**

### 4. 局部失敗不能拖垮整批

一列失敗就把原因寫進那一格，**其他列繼續跑**。

## 二、程式語言類

### 5. `String(undefined)` 是 `"undefined"` 五個字，不是空字串

```js
String(cell.getValue()).trim()   // ❌ 空白格拿回 undefined → 變成非空字串
```
判斷整個反過來，標題永遠補不上去。

**解法**：先判空再轉字串
```js
var v = cell.getValue();
var s = (v === undefined || v === null) ? '' : String(v).trim();
```

### 6. 語法上色器的兩個雷（本 skill 的 build_book.py 已修）

- **字串佔位符若只用數字**，會被「數字上色」規則吃掉，字串內容全變 0／1
  → 用 `\x00STR<n>\x00`
- **`class` 本身是關鍵字**，會回頭把剛產生的 `<span class="k">` 標籤裡的
  class 再上一次色，標籤就爛了
  → 關鍵字上色也要走佔位符 `\x00TAG<n>\x00`

## 三、平台類

### 7. 平台會偷改欄位／分頁名稱

Google 把「表單**回應** 1」改名為「表單**回覆** 1」，舊教學全部失效，第一次觸發就失敗。

**解法**：抓外部資源時**多種名稱都認得**
```js
function getRespSheet(ss) {
  var names = ['表單回覆 1', '表單回應 1', 'Form Responses 1'];
  for (var i = 0; i < names.length; i++) {
    var sh = ss.getSheetByName(names[i]);
    if (sh) return sh;
  }
  return null;
}
```

## 四、排版類

### 9. 一頁程式碼超過 28 行會溢頁

一頁程式碼 >28 行又要放 3 個解說框就會溢出。**長函式一律拆兩段。**
（`build_book.py` 的 `check_segments()` 會自動檢查）
