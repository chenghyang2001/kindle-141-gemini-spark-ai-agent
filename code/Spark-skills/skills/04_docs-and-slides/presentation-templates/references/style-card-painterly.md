# 卡片式繪畫筆觸（Card-style Painterly）

參考 vista.tw 的明亮暖色雜誌風，2026-07 為「打造 AI 商業分析儀表板」課程首頁定型。
核心感受：**明亮有朝氣、暖色米白底、白卡片、襯線標題有質感、每張卡配一張水彩手繪插畫**。
刻意避開深色底（學員反映深色「沒朝氣、想睡」）。

## 設計 Token（HTML/CSS）

```css
:root{
  --bg:#faf7f1;      /* 米白暖底（頁面背景） */
  --card:#ffffff;    /* 白卡片 */
  --line:#e8e2d6;    /* 細邊框（暖灰） */
  --ink:#2b2620;     /* 深棕黑主文字 */
  --muted:#7a6f60;   /* 次要文字 */
  --soft:#a89a86;    /* 更淡的說明/頁尾 */
  --red:#c0392b;     /* 重點色：CTA、章號、連結、「進入 →」 */
  --red-dark:#a53125;
  --gold:#b8860b;    /* 金色點綴：篇號、徽章、強調框 */
  --cream:#f5efe3;   /* 淺奶油：跑馬燈底、徽章底 */
  --serif:'Noto Serif TC','Songti TC',serif;  /* 標題＝襯線（招牌） */
  --sans:'Noto Sans TC',system-ui,'Microsoft JhengHei',sans-serif; /* 內文 */
}
```

字體是靈魂：**標題一律用 Noto Serif TC（600–900）**，內文 Noto Sans TC。襯線標題＋暖底＝雜誌感。

## 招牌元件

1. **跑馬燈公告列（.ticker）**：置頂、奶油底 `--cream`、細下邊框、紅字連結；純 CSS `@keyframes` 無縫左捲（內容重複兩份、translateX 0→-50%）、hover 暫停；每則是可點的 `<a>` 連到對應頁，不是純文字。
2. **Hero**：左文右圖 grid（1.15fr / .85fr）；徽章（cream 底 + gold 邊）→ 襯線大標（46px，關鍵字 `--red`）→ muted 副標 → 紅底白字 CTA（圓角 12px、陰影 rgba(192,57,43,.28)）；右側水彩插圖圓角 18px + 陰影。
3. **雜誌主題卡（.mag / .tvol）**：白卡、上方水彩插圖（aspect 4/3、圓角、hover 微放大 scale 1.04）、gold 篇號（字距 3px）、襯線篇名、**兩行有亮點的賣點文案**（不是說明、是勾人的一句）、紅色「進入本篇 →」底線 hover。
4. **編輯部目錄列（章節）**：每列＝紅色襯線章號（CH15）+ 粗體章名 + muted 副標 + 列尾紅「→」；列間細分隔線；hover 整列淡紅底 `#fdf1ef`。**用列表不用標籤膠囊**（標籤牆＝反例）。
5. **工具按鈕**：白卡 pill、hover 上浮 + 紅邊 + 陰影；重點項用 gold 邊框 + `#fffdf6` 底強調。
6. **作者卡 / 頁尾**：白卡置中、襯線名、社群鈕（YouTube 紅、FB 藍、Mail 綠）、頁尾 soft 小字 + 紅色警語。
7. **（選配）走動寵物吉祥物**：sprite 逐格走動 + 對話泡泡（鼓勵 + 課程相關話），詳見課程 `教學簡報/assets/pets.js`。

## 水彩插畫規格（用 FAL FLUX 生成，見 ai-media-generator）

- 風格：**溫暖水彩手繪插畫、米白暖色調背景、畫面無任何文字**。
- 一致性最重要：同一位主角（例：東亞青年在筆電前工作），各卡構圖不同、風格統一；生完逐張檢視，不一致就重生成。
- 比例：卡片插圖 4:3；Hero 用 16:9 最精緻那張。

## 版面與 RWD

- `.wrap` max-width 1240px；卡片圓角 14–18px；陰影統一 `0 x y rgba(43,38,32,.08~.12)`。
- 斷點：960px（雜誌卡 3→2 欄、hero 單欄圖在上）、600px（全單欄、標題縮字）。

## 何時用

課程首頁、招生 landing、資源入口、目錄頁——要「明亮、專業、有朝氣、雜誌感」時。
深色資料儀表板、簡報內頁（亮言 slides 引擎）不套這個，那些走既有深色系。
