# ch24｜延伸學習（Claude Code 版）

## 這章在講什麼

- 學完後怎麼持續學：追 Anthropic 官方資源（Claude Code 文件、更新紀錄、官方課程與部落格），再搭配中英文社群教學。
- 看別人教學要注意三件事：先看日期（Claude Code 更新頻繁，數月前的教學可能已過時，以你的畫面與官方文件為準）、注意作者用哪一版（Claude Code 版本、Pro／Max 或 API 計費、哪些連接器）、教學裡的指令與 CLAUDE.md 不要照抄。
- 把學習變成循環：把亂筆記整理成複習文件，標出「我學到的重點」「我還想弄清楚的」。
- 驗收重點：整理後的文件不能出現原筆記裡沒有的內容。
- 不同身分追不同主題，例如教師追教學應用與班級行政自動化。

## 作者做過的實驗／例子

- 原書示範把零散的聽課筆記，請 Spark 整理成四段複習文件並存成雲端文件。
- Claude Code 版：整理成本機 Markdown，再用 Google 雲端硬碟連接器存一份 Google 文件到「K141-課程練習」資料夾，並記入 cleanup.md。
- 驗收清單：重點有分類不是流水帳、沒有憑空新增內容、列出值得再查的問題。

## 演練

### 練習 1：把亂筆記整理成學習路線圖與複習文件

**目的**：練習「只整理、不加料」的筆記整理，產出下一階段學習路線，並實際存一份到雲端硬碟。
**送給練習視窗的提示詞**：

```text
請不要問我任何問題，直接完成。
1. 自行虛構一位國中老師看完一段 Claude Code 教學影片後的亂筆記（約 10 行，包含觀看日期、影片裡的 Claude Code 版本或方案、幾個零散重點、幾個疑問），存為 ch24/原始筆記.md，檔案開頭註明「虛構筆記」。
2. 只根據這份筆記，整理成 ch24/study-notes.md，必須有四段：1.我學到的重點（分類，不要流水帳）2.我實際動手做的 3.我還想弄清楚的（列成可再查的問題）4.下一步行動。硬規定：不可以出現原始筆記沒有的資訊；某段筆記沒有內容就寫「筆記未提及」。
3. 再加一節「學習路線圖」：三週，每週一個主題、一個在 Claude Code 動手的練習、一個查證任務。查證任務請你現在就先做第一週那一個：用 WebSearch 找 Anthropic 官方的 Claude Code 文件或更新紀錄頁，用 WebFetch 讀取，記下網址、查詢日期（今天日期請自己算）與頁面上顯示的最新版本或更新日期；查不到就寫「查詢失敗」。不要憑記憶寫網址。並加一條提醒「看別人教學前先看日期與版本」。
4. 把 study-notes.md 的內容用 Google 雲端硬碟連接器建立一份 Google 文件，標題為「課程練習｜ch24 複習文件」，放在雲端硬碟資料夾「K141-課程練習」（沒有就建立這個資料夾）。安全規則：不刪除、不移動、不修改任何非本次建立的檔案；只建立這一份文件（以及必要時的資料夾）。
5. 把本次建立的東西（類型、標題、ID）附加寫進 ch24/cleanup.md，供控制台事後清除。
6. 完成後自我檢查：逐條列出 study-notes.md 有沒有加料，並回報。
```

**觀察重點**：

- 整理後的文件有沒有悄悄加了原筆記沒有的內容？自我檢查是否誠實？
- 查證任務是否真的上網查、附網址與日期，而不是背出一個網址。
- 雲端文件標題、資料夾是否照規則，cleanup.md 有沒有記下 ID。

## 教練解說要點

- 學習循環：看教學、動手做、整理、標出未解問題、再查證，下一輪才有方向。
- 整理類任務最容易「幫你加料」，驗收一律檢查有無新增內容。
- 會碰真實帳號的動作，一律限定標題、資料夾與清除紀錄，這是長期使用代理人的好習慣。
