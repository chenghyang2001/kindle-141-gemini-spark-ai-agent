# ch06｜設好排程，早上 7 點自動報到：雲端 routine

## 這章在講什麼

- 排程是聊天工具和「代理人」拉開差距的地方：設定一次，它每天固定時間自己讀資料、算統計、更新文件。Claude Code 版用 claude.ai 雲端排程 routines（`/schedule`）。
- 排程的提示詞寫法和一般任務一樣，但因為你不在現場要更保守：出錯可能幾天後才發現，它問你也沒人回答。
- 排程三原則：能唯讀就唯讀；產出放固定位置（避免一個月後多出三十份檔案）；要留下時間戳。
- 「怎麼關掉」和建立同等重要：排程會一直消耗額度，練習用的排程驗收完一定要停用或刪除。

## 作者做過的實驗／例子

- 原書：每天早上讀班級紀錄分頁，統計請假、出席、遲到各幾筆，更新到固定名稱的文件，最後一行寫更新時間。Claude Code 版：來源放雲端硬碟「K141-課程練習」，輸出更新同一份固定名稱的雲端文件。
- 原書：用「立即執行」驗收，它會回報「只讀取指定分頁、沒修改內容、沒寄信」。Claude Code 版：先在練習視窗手動跑一次同一份提示詞，再由控制台建 routine、立即執行一次、刪除。
- 對照表：交辦當下的任務 vs 排程，差別在可見度、能否互動、權限與結果存放。

## 演練

### 練習 1：設計一張安全的排程設計單

**目的**：把排程三原則寫成具體的 routine 提示詞，並把權限邊界寫死。
**控制台接手**：控制台讀 ch06/ex1.md，用 `/schedule` 建立 routine「課程練習_每日報名摘要」（每天 07:00，台北時間），按一次立即執行並確認雲端文件有更新，驗收後立刻刪除該 routine，把 routine 名稱與 ID 補進 ch06/cleanup.md。
**送給練習視窗的提示詞**：

```text
這是課程練習，會用到我的真實 Google 雲端硬碟。安全規則：雲端檔案名稱以「課程練習_」開頭，只放在資料夾「K141-課程練習」，不分享、不寄信、不修改或刪除既有檔案。你不用建立排程，排程由控制台建立。
情境（虛構）：某社團有一份「活動報名紀錄」，每天要統計新增報名人數、已繳費人數、待跟進人數。
1. 自行虛構 6 列報名資料（日期、姓名、是否繳費、是否待跟進），存成 ch06/signup-records.csv，並在「K141-課程練習」建一份雲端檔案「課程練習_活動報名紀錄」（能轉 Google 試算表就轉；資料夾不存在就建立）。
2. 寫排程設計單 ch06/ex1.md，包含：
   - 排程名稱「課程練習_每日報名摘要」、執行時間每天 07:00（台北時間）
   - 完整 routine 提示詞，用七欄位寫：只讀「課程練習_活動報名紀錄」、統計三個數字、更新固定一份雲端文件「課程練習_每日摘要」（不存在才建立，存在就覆寫內容，不要每天新建）、最後一行寫更新時間、權限邊界寫明不修改來源、不寄信、不分享
   - 逐條標出提示詞落實了「能唯讀就唯讀」「產出放固定位置」「要留時間戳」哪一條
   - 「怎麼關掉」：停用與刪除 routine 的步驟，以及什麼情況下該停用
3. 把新建的雲端資料夾與檔案（類型、名稱、ID）附加寫進 ch06/cleanup.md。
```

**觀察重點**：

- 權限邊界有沒有寫出「不修改來源」「不寄信」這類明確禁令？
- 輸出位置是不是固定的一份文件，而不是「每天新建一份」？
- 「怎麼關掉」有沒有被當成設計的一部分，而不是事後補充？

### 練習 2：手動跑一次 routine 提示詞，檢查它有沒有守規矩

**目的**：對應書中「立即執行」驗收，在交給排程前先親眼看一次結果。
**送給練習視窗的提示詞**：

```text
這是課程練習。請讀 ch06/ex1.md 裡的 routine 提示詞，現在就照它真的執行一次（雲端安全規則同練習 1：只讀來源、只寫「課程練習_每日摘要」、不分享、不寄信、不動其他檔案）。
1. 從雲端硬碟讀「課程練習_活動報名紀錄」，列出讀到的資料。
2. 算出三個統計數字，並列出計算過程方便我核對。
3. 在「K141-課程練習」建立或更新雲端文件「課程練習_每日摘要」，最後一行寫更新時間（台北時間）。
4. 把以上結果和「守規矩回報」存成 ch06/ex2.md：逐條說明有沒有只讀取、有沒有修改來源、有沒有寄信、有沒有分享。
5. 主動挑出 1 個可能出錯的地方（例如日期判斷、時區、重複計算），說明我該怎麼核對。不要假裝一切完美。
6. 若有新建「課程練習_每日摘要」，把它（類型、名稱、ID）附加寫進 ch06/cleanup.md。
```

**觀察重點**：

- 統計數字能不能由來源資料自己重算出來？
- 「守規矩回報」是不是逐條對應權限邊界？來源檔的修改時間有沒有變？
- 它主動指出的風險點有沒有道理？真實排程出錯可能幾天後才發現，這個習慣很重要。

## 教練解說要點

- 排程的重點不是「自動」，而是「不在場也不出事」：保守權限、固定位置、時間戳三件事。
- 先在練習視窗手動跑過，再交給雲端 routine；驗收完立刻刪除，這是本章「怎麼收拾」的精神。
- 提醒觀眾：依 ch06/cleanup.md 確認 routine 已刪、雲端檔案已清。
