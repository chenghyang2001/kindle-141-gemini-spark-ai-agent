# ch04｜一句話登記，試算表自己長：用雲端硬碟連接器建表

## 這章在講什麼

- 本章讓 Claude Code 建一份學員名單試算表，之後用一句話就能登記出缺席。Claude Code 版：本機先產生 CSV，再用 Google 雲端硬碟連接器建成雲端試算表。
- 作者先示範「同一句話兩種講法」：只說「建一份名單試算表」，結果檔名自取、欄位變多，甚至憑空多出三個人，配上假信箱與電話。
- 原因是 AI 在填你沒說清楚的空白；所以重點不是怎麼建表，而是怎麼把話講到沒有空白可填。
- 完整指令包含：檔名、分頁名、第一列標題欄位、照抄資料不增不減，以及不寄信、不改其他檔案的邊界。
- 建好之後，用一句話在「紀錄」表一次登記多筆，並回報目前總列數。

## 作者做過的實驗／例子

- 原書：一句話版本多出欄位、多出三個人、標題列從第 2 列開始；完整指令版本欄位正好五個、十筆一筆不多不少。Claude Code 版：同樣做 A／B 兩版 CSV 比較，B 版才上傳成雲端試算表。
- 原書：登記三筆後紀錄分頁變成五列（標題加四筆）。Claude Code 版：登記後把雲端檔案讀回來數列數，不只相信它說的。
- 作者提醒這一步實測跑了好幾分鐘，要先確認它是否還在處理中。

## 演練

### 練習 1：把話講到沒有空白，產出名單並上傳雲端

**目的**：親眼比較「模糊指令」與「無空白指令」，並把乾淨的那版真的建到雲端硬碟。
**送給練習視窗的提示詞**：

```text
這是課程練習，會用到我的真實 Google 雲端硬碟。安全規則：雲端檔案名稱一律以「課程練習_」開頭，只放在資料夾「K141-課程練習」；不分享給任何人、不寄信、不修改或刪除任何既有檔案。
1. 自己虛構 8 位「社團成員」（編號、姓名、組別、身分、備註，註明虛構）。
2. 版本 A（模糊）：當作我只說「幫我建一份社團名單」，誠實做出一個你會自行補上額外欄位或人員的版本，標出哪些是自作主張，存成 ch04/ex1-a.csv。
3. 版本 B（無空白）：檔名 member-roster、標題欄位正好是「編號、姓名、組別、身分、備註」在第 1 列、8 筆不增不減、不得新增欄位與人員，存成 ch04/ex1-b.csv。
4. 在雲端硬碟搜尋資料夾「K141-課程練習」，沒有就建立；再把版本 B 建成 Google 試算表「課程練習_member-roster」放進去（若無法轉成試算表，就上傳 CSV 並註明）。
5. 在 ch04/ex1-compare.md 用表格比較兩版的欄位數、資料筆數、多出來的內容，三句話說明差異，並附雲端檔案連結。
6. 把本次在雲端建立的資料夾與檔案（類型、名稱、ID）附加寫進 ch04/cleanup.md。
```

**觀察重點**：

- B 版是否正好 8 筆、標題在第 1 列、沒有多出聯絡方式？
- A 版的自作主張清單，是否和書中「憑空多出的人」類似？
- 雲端硬碟上是否只多了一個「K141-課程練習」資料夾和一個檔案，且沒有被分享？

### 練習 2：一句話登記，並讀回來核對總列數

**目的**：驗證建好表之後，簡短口令也能穩定寫入，而且能自己讀回來核對數量。
**送給練習視窗的提示詞**：

```text
這是課程練習，沿用 ch04/ex1-b.csv 的名單；雲端安全規則同練習 1（「課程練習_」前綴、只放「K141-課程練習」、不分享、不改其他檔案、不寄信）。
1. 建立 ch04/ex2-records.csv，標題列：日期、姓名、狀態、原因。依這句口令一次登記三筆：
「登記 某甲 遲到 交通延誤；登記 某乙 出席 全程參與；登記 某丙 請假 公假」
某甲、某乙、某丙請換成名單裡的三位成員（不可用名單外的人），日期用今天。
2. 把它建成雲端檔案「課程練習_attendance-records」放進「K141-課程練習」（能轉 Google 試算表就轉）。
3. 用雲端硬碟工具把這個檔案的內容讀回來，數總列數（含標題）。
4. 存 ch04/ex2-report.md：讀回來的總列數、三個名字是否都在名單內；若總列數不是 4，指出哪裡錯，不要直接宣稱全部正確。
5. 把新建的雲端檔案（類型、名稱、ID）附加寫進 ch04/cleanup.md。
```

**觀察重點**：

- 讀回來的檔案是否為 1 列標題加 3 筆資料，共 4 列？
- 三個名字是否都來自名單，沒有新發明的人？
- 自我核對是根據讀回來的內容，還是只憑記憶宣稱正確？

## 教練解說要點

- 本章答案是「把話講到沒有空白可填」，不是學會某個試算表功能。
- 假資料看起來越像真的越危險；真實使用時，最容易幾個月後才發現被補進去的假資料。
- 提醒觀眾：「不要自己編造人名」與「不寄信、不改別的檔案」要永遠留著；練完依 ch04/cleanup.md 清掉雲端檔案。
