# ch02｜收件匣不再爆炸：用 Gmail 連接器只存草稿

## 這章在講什麼

- 本章讓 Claude Code 透過 Gmail 連接器真的處理信件，但先建立安全做法：測試信主旨一律以「課程練習」開頭，指令限定「只處理主旨以此開頭的信」，確保不動到真實信件。
- 評估動作風險看三件事，其中之一是「能不能復原」：封存、加標籤、標示已讀套到真信件上，要一封一封改回來。
- 回覆一律先存草稿（`create_draft`），不直接寄出。寄出就收不回來，AI 寫的回覆常見語氣不對或誤會對方意思。
- 凡是會離開你電腦的動作，都先停在你眼前；邊界要寫死在指令裡，不能靠它自己問。
- 驗收看「執行回報」，再到 Gmail 實際搜尋確認。

## 作者做過的實驗／例子

- 原書：先寄 5 封練習信給自己（含一封電子報），讓 Spark 分類、擬草稿、加標籤。Claude Code 版：由練習視窗先用 `create_draft` 建 5 封「課程練習」草稿模擬收件，不寄出任何信。
- 原書：最後在 Gmail 搜尋確認標籤只貼在那一封；作者強調「只有 1 封」比「有加到標籤」更值得確認。Claude Code 版：用 `search_threads` 搜標籤，數一數結果。
- 作者說 AI 出錯的方式通常是做太多。

## 演練

### 練習 1：建練習信並擬回覆草稿，絕不寄出

**目的**：用真的 Gmail 體驗「對外動作先停在眼前」，並檢查草稿品質。
**送給練習視窗的提示詞**：

```text
這是課程練習，會用到我的真實 Gmail，請嚴格遵守安全規則：
- 絕對不可寄出任何信：不可使用 send_message、reply、forward，只能用 create_draft。
- 只處理主旨以「課程練習」開頭的信；其他信件不讀內容、不改、不刪、不加標籤。
- 不刪除、不封存任何不是本次建立的東西。
步驟：
1. 用 Gmail 搜尋 subject:課程練習，回報有幾封（只看主旨）。
2. 用 create_draft 建 5 封草稿模擬收件，收件人填我自己的信箱，主旨都以「課程練習｜」開頭：同事問會議時間、供應商詢問報價、朋友邀約聚餐、一封電子報、一封像釣魚的可疑通知。內容虛構、短短兩三句。
3. 對其中需要回覆的信（同事、供應商、朋友）各再建一封回覆草稿，主旨「課程練習｜回覆：…」，語氣自然、先講結論，不要編造電話或地址。可疑通知不回覆，只標註風險原因。
4. 把每封草稿的主旨、草稿 ID、用途寫進 ch02/ex1-inbox.md，最後加「執行回報」：逐條說明遵守了哪些限制，並列出哪些動作你「沒有做」。
5. 把本次建立的所有草稿（類型、主旨、ID）附加寫進 ch02/cleanup.md，供事後清除。
```

**觀察重點**：

- Gmail 草稿匣是否多了 8 封「課程練習」草稿，寄件備份裡什麼都沒有？
- 可疑信有沒有被當成需要回覆的信？
- 「沒有做」的清單能不能和禁止事項一一對上？cleanup.md 的 ID 是否齊全？

### 練習 2：標籤只貼在該貼的那一封

**目的**：用真的 Gmail 標籤驗收「做太多」的問題，並寫出夠窄的判斷條件。
**送給練習視窗的提示詞**：

```text
接續 ch02/ex1-inbox.md，只處理裡面那 5 封「課程練習｜」模擬收件草稿，仍然不可寄出任何信。
任務：只替「電子報」那一封加上標籤「課程練習_電子報」，其餘四封一律不動，不封存、不標已讀、不刪除。
1. 先寫出你判斷「什麼算電子報」的條件，至少三條，要具體到外人能重現，避免誤傷朋友邀約。
2. 若 Gmail 沒有「課程練習_電子報」這個標籤就用 create_label 建立，再把它加到電子報那一封。若草稿無法加標籤，就照實回報錯誤訊息，不要改去標其他信。
3. 用 search_threads 搜尋 label:課程練習_電子報，回報實際找到幾封。
4. 輸出表格存成 ch02/ex2-labels.md：5 封各一列，欄位「主旨、判斷為電子報嗎、理由、有沒有被加標籤」，並寫出搜尋結果筆數；若不是 1 封，說明哪個條件太寬並改寫。
5. 把新建的標籤（類型、名稱、ID）附加寫進 ch02/cleanup.md。
```

**觀察重點**：

- 搜尋結果是否正好 1 封？不是的話，是判斷條件太寬。
- 判斷條件是否可被外人重現，而不是「看起來像電子報」這種模糊說法。
- 遇到工具做不到時，它是老實回報，還是自作主張改標別封？

## 教練解說要點

- 安全三原則：用「課程練習」前綴隔離、回信一律存草稿、邊界寫在指令裡。
- 「先在不痛不癢的地方試」是整本書的方法論；草稿和專用標籤就是不痛不癢的地方。
- 提醒觀眾：練習完請自己到 Gmail 看草稿匣與標籤，並依 ch02/cleanup.md 清掉。
