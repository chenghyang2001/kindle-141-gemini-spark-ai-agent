# ch05｜一次生成多頁簡報：大綱交給 Claude Code，成品交給 Artifact

## 這章在講什麼

- 做簡報最耗時的是把重點排成一頁一頁的版面。本章把「排版、分頁、配色」交給 AI，使用者只寫純文字大綱。
- 分工界線：結構、文字、頁數由人決定；版面、配色、字級由 AI 決定。想要特定風格就寫進指令（例如白底黑字、不要科技風）。
- 指令一樣用七欄位，大綱整段放在「執行步驟」。
- 原書產出可編輯的 Google 簡報；Claude Code 版由練習視窗寫出逐頁內容檔，再由控制台發布成 claude.ai Artifact 簡報。做完一樣要數頁數、查有沒有被偷加內容。

## 作者做過的實驗／例子

- 原書：8 頁「AI 代理人入門」簡報，給 8 頁大綱就出 8 頁，約跑 5 分鐘。Claude Code 版：練習視窗產出逐頁 Markdown，控制台再做成 Artifact 簡報檢查頁數。
- 對照表：含糊的「幫我做簡報」與逐頁列出標題和重點的指令，結果差很多。
- 常見三問題：頁數不對 → 寫成「第 N 頁」並加「不要自己增加頁數」；多了沒講的內容 → 加「不要自己編造數據或案例」；不喜歡版面 → 在指令裡指定風格。

## 演練

### 練習 1：用七欄位指令把大綱變成 6 頁簡報

**目的**：體驗「只給結構、版面交給 AI」的分工，並看它會不會守住頁數。
**控制台接手**：練習視窗寫完 ch05/ex1.md 後，控制台讀這個檔，把 6 頁發布成 claude.ai Artifact 簡報（白底黑字、不要深色科技風），核對頁數是否為 6，把 Artifact 連結補進 ch05/cleanup.md。
**送給練習視窗的提示詞**：

```text
請依下面這份七欄位指令，自己虛構一份「新人上班第一週導覽」的 6 頁大綱，再把它做成簡報內容，存成 ch05/ex1.md。格式：每頁用「## 第 N 頁：標題」分隔，底下 3 到 4 個重點，每頁最後一行寫「版面建議：…」。

目標：把大綱做成之後要發布成簡報的逐頁內容。
資料來源：只用大綱本身，不要上網、不要補充外部資料。
執行步驟：依大綱每個大項一頁，共 6 頁。
判斷規則：不要自己增加頁數，不要自己編造數據或案例，每頁文字精簡。風格：白底黑字、素雅，不要深色科技風。
輸出位置與格式：ch05/ex1.md（簡報成品由控制台另外發布，你不用發布）。
時間或觸發：現在執行一次。
權限邊界：不要呼叫任何 Gmail／日曆／雲端硬碟工具，不要動 ch05/ 以外的檔案。

做完後在檔案最下方補一段「自我檢查」：實際頁數幾頁、有沒有任何內容不在大綱裡。
```

**觀察重點**：

- 檔案是不是剛好 6 頁？控制台發布後的 Artifact 也是 6 頁嗎？
- 七個欄位裡哪一欄在防止「自己加料」？拿掉它會怎樣？
- 「版面建議」就是分工界線：它決定版面，你決定內容。

### 練習 2：大綱太含糊時，AI 會怎麼自己決定

**目的**：對照「含糊指令」與「結構化指令」，理解為什麼要寫「第 N 頁」這種格式。
**送給練習視窗的提示詞**：

```text
做兩次對照實驗，結果存成 ch05/ex2.md。主題自己虛構：「小型咖啡店的新品上市簡報」。只寫本機檔案，不要呼叫任何連接器工具。
第一次：當作我只丟一句「幫我做一份簡報」，你照自己的理解直接寫出逐頁內容，並誠實記錄你自己決定了幾頁、每頁放什麼、有沒有加入我沒講的內容（例如編出來的價格或銷售數字）。
第二次：先自己擬 5 頁大綱（格式「第 N 頁 標題：重點、重點、重點」），再加上「不要自己增加頁數、不要編造數據」，重做一次。
最後用表格比較兩次：頁數、是否有編造內容、你的自信程度，並用三句話總結「為什麼大綱要寫成第 N 頁的形式」。
```

**觀察重點**：

- 第一次的頁數與內容是誰決定的？有沒有憑空編出的數字？
- 第二次的輸出是否更貼近大綱？
- 把這個差別對照到書裡的「卡住了先看這三招」。

## 教練解說要點

- 本章核心是「分工的界線」：人管結構與內容，AI 管版面；界線畫不清就會被它自己補料。
- Claude Code 版的分工多一層：練習視窗產內容，控制台發布 Artifact；發布後一樣要數頁數。
- 驗收不能省：數頁數、查有沒有加料、最後自己微調，這才是從「初稿」變成「你的簡報」。
