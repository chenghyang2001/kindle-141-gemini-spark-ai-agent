# ch07｜教 Claude Code 一個新技能（Skills）

## 這章在講什麼

- 技能不是一段對話，而是一份長期生效的規則書：寫一次，之後不必重述細節，Claude Code 自己照做。
- Claude Code 的技能是一個資料夾加一份 `SKILL.md`：開頭 frontmatter 有 `name`（全小寫、連字號）與 `description`（什麼時候該啟用），正文是使用說明（規則、格式、邊界逐條寫）。
- 技能放在專案的 `.claude/skills/<名稱>/SKILL.md` 就會被載入；可以用 `/<名稱>` 直接呼叫，也會在你的說法符合 description 時自動出場。
- 常見寫錯：名稱用中文或空格、description 寫成功能簡介、正文只寫一句話。

## 作者做過的實驗／例子

- 原書在 Spark 為班級出缺席登記建技能：名稱英文小寫加連字號、說明列出「登記」「彙整出缺席」等平常說法、使用說明寫七條規則。Claude Code 版改成真的寫一份 `SKILL.md` 到 `.claude/skills/`。
- 說明欄只寫「處理出缺席」的話，講「登記」時它可能不出場；Claude Code 的 description 一樣是決定觸發的關鍵欄位。
- 書附技能庫可拿來對照寫法；本演練放在 `Spark-skills/`，格式與 Claude Code 的 SKILL.md 相通。

## 演練

### 練習 1：寫一個真的能用的 Claude Code 技能

**目的**：把「平常會講的話」寫進 description，把規則條列進正文，存成 Claude Code 會載入的位置。
**送給練習視窗的提示詞**：

```text
請幫我建立一個 Claude Code 技能「讀書會簽到登記」，存成 .claude/skills/book-club-checkin/SKILL.md（相對於 practice/）。情境由你虛構：每週一次的讀書會，要記錄出席、請假、遲到，資料存在 ch07/checkin.csv。
SKILL.md 格式：
1. 開頭 frontmatter：name 用全小寫英文加連字號；description 寫清楚什麼時候該啟用，至少列出 5 種我平常可能會說的說法（口語、簡短、同義詞都要有），並寫一句「不觸發」的情境。
2. 正文：6 到 8 條編號規則，涵蓋資料放哪、哪些只讀不改、欄位順序、日期格式、可接受的類別（出席／請假／遲到）、彙整方式、完成後怎麼回報（要寫「不寄信」）。
可以先瀏覽 Spark-skills/ 底下任一個 SKILL.md 參考結構與語氣，但內容用自己的情境重寫。
另存 ch07/ex1.md：貼出技能全文，並附一段「為什麼 name 不用中文、description 不寫成功能簡介」的說明，最後寫「重開 Claude Code 後可用 /book-club-checkin 呼叫」。
```

**觀察重點**：

- description 的口語說法夠不夠多？少了哪一種說法，技能可能就不會被叫到？
- 正文是不是一條一條的規則，而不是一句話？
- 檔案是否真的放在 `.claude/skills/book-club-checkin/SKILL.md`，frontmatter 格式正確？

### 練習 2：觸發測試，找出 description 的漏洞

**目的**：驗證 description 是否涵蓋各種講法，體會「說明寫不好，技能不出場」。
**送給練習視窗的提示詞**：

```text
接續上一個練習，請讀 .claude/skills/book-club-checkin/SKILL.md，做一次觸發測試，結果存成 ch07/ex2.md：
1. 自己擬 8 句我可能對 Claude Code 說的話（4 句應該觸發、2 句不該觸發、2 句模稜兩可）。
2. 針對每一句，依 description 的文字判斷這個技能會不會被啟用，並說明理由。
3. 找出被漏掉的說法，直接修改 SKILL.md 的 description，再重新判斷一次。
4. 用表格呈現修改前後的觸發結果。
5. 最後實際挑一句「應該觸發」的話照技能規則執行一次：在 ch07/checkin.csv 新增一筆虛構簽到，並依技能的回報格式回報。
所有句子與資料由你自己虛構，不需要問我。
```

**觀察重點**：

- 「模稜兩可」的句子是否暴露了 description 的缺口？
- 修改後有沒有誤觸發（不該觸發的也被叫出來）？
- 實際執行時，CSV 欄位順序與回報格式是否完全照 SKILL.md？

## 教練解說要點

- 技能是規則書，不是範例對話：description 管「何時出場」，正文管「怎麼做」。
- description 要寫成你平常的說法，別寫成產品簡介；這在 Spark 和 Claude Code 都一樣。
- 練習 2 的觸發判斷是 Claude 依文字推論；真正是否自動出場，要重開 session 實際講一次才準。
