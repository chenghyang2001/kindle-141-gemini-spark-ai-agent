# ch17｜畢業製作：用 Claude Code 打造自己的 AI 秘書

## 這章在講什麼

- 學完工具後最常見的狀況不是不會用，而是不知道拿它做什麼，因為前面每章都幫你決定好了題目。回到自己的現場，沒人給題目。
- 所以本章先填一張七問規劃表：你是誰、想解決什麼（一句話）、資料放哪裡、要教它什麼規則、什麼時候自動跑、什麼情況算成功、不准它做什麼。Claude Code 版會把其中的「規則」寫成專案 CLAUDE.md，讓它每次開工都自動讀到。
- 流程：填規劃表 → 自己建好試算表與分頁 → 第一段做教案與板書 → 第二段做提問階梯與題庫 → 每段做完都自己開檔案看一眼 → 六件成品驗收加安全檢核 → 最後一問：能講給別人聽嗎？
- 重要提醒：分頁與試算表這類基礎建設要自己建，不要交給 AI。

## 作者做過的實驗／例子

- 原書以「一堂課的備課工作流」為範例：先產出教案，把板書做成三層樹狀結構，可以直接抄到黑板上。Claude Code 版一樣做，並把教案放上雲端硬碟成為 Google 文件。
- 第二段原書要做三個分頁的題庫試算表，這一步自己動手；Claude Code 版只產出可匯入的 CSV 內容，試算表由你自己建。
- 七個欄位不是要取代你思考，而是把想法排成格式。

## 演練

### 練習 1：七問規劃表、秘書規則與備課教案

**目的**：先想清楚再動手，體驗規劃表與 CLAUDE.md 如何讓後面的指令變簡單。
**送給練習視窗的提示詞**：

```text
請幫一位虛構的國中自然科老師「周老師」完成畢業製作第一段。資料都由你自擬，不要問我。存到 ch17/。
安全規則：雲端檔案標題以「課程練習」開頭、放在雲端硬碟資料夾「K141-課程練習」（不存在就建立）；不修改、不刪除任何非本次建立的檔案。
1. plan.md：用表格填完七問（我是誰、我想解決什麼（一句話）、資料放哪裡、要教它什麼規則（三條）、什麼時候自動跑（不確定就寫「先不用排程」）、什麼情況算成功、不准它做什麼）。
2. CLAUDE.md（放在 ch17/ 底下）：把七問裡的規則與「不准做什麼」改寫成周老師的 AI 秘書常駐規則，15 行內。
3. lesson-plan.md：以「凹面鏡與凸面鏡」為主題，一堂 45 分鐘教案：學習目標、流程時間表、提問、課後作業。最後附一行：這份教案只是範例，實際授課要依課綱與教科書版本調整。
4. board.md：板書做成三層樹狀結構（大標、小標、重點），要能直接抄到黑板。
5. 用 Google 雲端硬碟連接器把 lesson-plan.md 建成 Google 文件，標題「課程練習-周老師教案」，放進「K141-課程練習」；做不到就註明原因。
6. 把本次建立的雲端物件（類型、標題、檔案 ID）附加寫進 ch17/cleanup.md。
```

**觀察重點**：

- 七問中「一句話」能不能真的講完？講不完代表想做的事太多。
- CLAUDE.md 的規則是否具體到可以驗收，而不是「要清楚」之類空話？
- 板書三層結構是否真的能抄到黑板上？

### 練習 2：題庫、驗收表與「能講給別人聽嗎」

**目的**：完成第二段並用驗收表與安全檢核收尾，最後用一問檢查自己是否真的懂。
**送給練習視窗的提示詞**：

```text
延續周老師的情境，先讀 ch17/CLAUDE.md 並遵守其中規則，存到 ch17/：
1. questions.md：依「凹面鏡與凸面鏡」做提問階梯（由淺入深 5 題：回憶、理解、應用、分析、評估），每題附參考答案要點。
2. quiz-bank.csv：題庫內容，欄位：題號、題幹、選項A、選項B、選項C、選項D、答案、難度，共 6 題。這只是可匯入的內容，試算表與分頁由我自己建，你不要在雲端硬碟建立試算表。
3. acceptance.md：「六件成品驗收表」（成品、是否存在、我怎麼確認、通過/未通過），成品包含練習 1 建立的 Google 文件；以及「安全檢核五項」（個資、對外送出、可否撤銷、出錯多久會發現、我驗不驗得動）。先預填你的判斷，但「我怎麼確認」欄註明需要我自己開檔案確認。
4. explain.md：150 字內的「講給同事聽」稿：這個 AI 秘書幫我做什麼、哪裡我一定自己檢查、哪裡不交給它。
```

**觀察重點**：

- 題庫答案是否正確？自己挑兩題驗證。
- 它有沒有遵守 CLAUDE.md 的規則，並且沒有自作主張去建試算表？
- 講給同事聽的稿，能不能不用任何術語就講清楚？

## 教練解說要點

- 沒有題目的時候，先填表比先下指令更有效；填完的規則寫進 CLAUDE.md，就不用每次重講。
- 分頁、檔案這種基礎建設自己建，AI 做在上面的內容。
- 「能講給別人聽」是最後的驗收，講不出來代表還沒真的理解。
