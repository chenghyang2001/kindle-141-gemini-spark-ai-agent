# ch22｜素材與圖庫（Claude Code 版）

## 這章在講什麼

- 原書介紹免費圖庫，以及用圖前一定要先弄清楚的授權問題；換成 Claude Code 做簡報或 Artifact 時，這套規則完全不變。
- 授權要看三件事：可不可以商用（收費課程、公司提案都算商用）、要不要標示出處、可不可以修改（裁切、加字、調色是否算修改，各家規定不同）。
- 每個圖庫都有授權說明頁，用之前先讀；Claude Code 可以用 WebFetch 幫你摘要，但條款原文仍要自己看一眼。
- 不叫 AI 直接配圖：授權責任在你、它挑的圖未必適合場合。改叫它寫「配圖建議」，圖自己去挑。
- 挑圖流程：看建議、到圖庫用英文關鍵字搜尋、確認授權、下載存素材夾、簡報最後一頁加「圖片來源」。

## 作者做過的實驗／例子

- 原書讓 Spark 針對一份簡報，每頁產出「適合找什麼畫面」的建議；Claude Code 版做法相同，產出的內容檔之後可交給控制台發布成 Artifact 簡報。
- Claude Code 版多一步：用 WebSearch／WebFetch 查圖庫授權頁現況，並記下查詢日期，提醒條款會變。
- 使用注意：肖像權和圖片授權是兩回事。

## 演練

### 練習 1：素材授權檢查清單＋配圖建議

**目的**：把「授權三件事」變成每次用圖都能照著勾的清單，並練習只請 AI 給建議、不請它挑圖。
**送給練習視窗的提示詞**：

```text
請不要問我任何問題，直接完成。這個練習只寫檔案，不要下載任何圖片，也不要操作任何帳號。
請自行虛構一份「國中社會課：台灣水資源」的 6 頁簡報大綱。
請在 ch22/素材檢查.md 完成：
1. 「配圖建議」表：每頁一列，欄位為頁碼、頁面主旨、建議找什麼樣的畫面、建議的英文搜尋關鍵字。只寫建議，不要指定任何具體圖片或圖片網址，也不要假裝你看過哪張圖。
2. 「圖庫授權現況」表：用 WebSearch 找 3 個常見的免費圖庫，再用 WebFetch 讀各自的授權說明頁，整理「可否商用、需否標示出處、可否修改、特別限制」四欄；每列附上你實際讀到的授權頁網址與查詢日期（今天日期請自己算），讀不到的寫「查詢失敗，需自行查看」，不要憑印象填。
3. 「授權檢查清單」：每張圖要勾的項目至少包含可不可以商用、要不要標示出處、可不可以裁切加字調色、是否含可辨識的人臉（肖像權）、授權頁看過的日期。做成可重複複製使用的表格。
4. 「圖片來源」範本：簡報最後一頁的格式，欄位用【佔位符】留白。
5. 一段提醒：為什麼條款可能改變，所以不能只信這份清單與你今天的摘要。
```

**觀察重點**：

- 有沒有守住「只給建議，不指定具體圖片」？
- 授權現況表是否每列都有實際網址與查詢日期？查不到時有沒有老實寫「查詢失敗」。
- 清單是否涵蓋三件事外的肖像權。

## 教練解說要點

- 授權責任永遠在使用者身上，AI 只能幫你整理流程與摘要條款，不能替你確認授權。
- 配圖建議省下的是想畫面的時間，不是確認授權的時間。
- 加上「圖片來源」頁，是三個月後自己改簡報時會慶幸的小習慣。
